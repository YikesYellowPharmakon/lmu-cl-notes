语句
Anweisungen

Folie 5
  • Anweisungen (Statements, Befehle) sind die Grundelemente imperativer Programmiersprachen zur Festlegung (Kontrolle) des Ablaufs eines Programms.
  • Syntax (wird im Laufe der Vorlesung noch erweitert) 
    Statement = Assignment   (Zuweisung)
          | Conditional  (Fallunterscheidung)
          | Iteration    (Wiederholung)
Block     = Statement { Statement }
  • Durch Ausführung einer Anweisung wird ein „alter“ Zustand σ in einen „neuen“ Zustand σ′ überführt.
    Notation: σ Statement σ′

Anweisung 语句 (英语 statement, 也叫 Befehl 命令) 是命令式语言的基本单位, 规定程序的执行流程. 和表达式的区别: 表达式算出一个值, 语句做一件事 (改变状态).

目前有三种语句: 赋值、条件、循环. Block 块 是一个或多个语句排在一起. 每执行一条语句, 旧状态 σ 变成新状态 σ′.

赋值
Zuweisungen

Folie 6

Syntax:
Assignment = Variable "=" Expression

Wirkung:

  1. Zunächst wird der Wert von Expression im „alten“ Zustand berechnet.
  2. Dieser Wert wird im Nachfolgezustand der Variablen Variable als neuer Wert zugewiesen.

Beispiel:

[(x, 5, int), (y, 7, int)]
x = 2*x + y =σ 2*5 + 7 =σ 17
[(x, 17, int), (y, 7, int)]

Beachte den Unterschied zwischen Zuweisung „=“, Vergleich „==“, sowie Auswertung von Ausdrücken =σ

赋值的效果分两步, 顺序很重要:

  1. 先在旧状态下算出右边表达式的值;
  2. 再把这个值存进左边的变量, 得到新状态.

所以 x = 2*x + y 不是数学方程 (数学上它要求 x = −y), 而是「用 x 的旧值算出新值」: 旧 x = 5, 算出 17, 再存回 x.

三个容易混的符号:

符号含义属于
=赋值: 把右边的值存进左边Python 语句
==比较: 两边相等吗? 结果是 True/FalsePython 表达式
=σ「在状态 σ 下求值等于」, 写求值过程用课堂上的数学记号, 不是 Python
Folie 7

Zuweisungen (Syntax und Wirkung wie Folie 6)

Allgemein: für σ x = e σ′

  • Berechne Wert v mit Typ t von e in σ, also e =σ v
  • Aktualisiere (x, ?, ?) in σ zu (x, v, t) in σ′

一般规则: 执行 x = e 时, 先在 σ 下算出 e 的值 v 和类型 t; 然后把状态里 x 那一项 (原来是什么都无所谓, 记作 (x, ?, ?); x 原来不存在就新增一项) 改成 (x, v, t). 其他变量不变.

Abkürzungen:

x += 1steht für x = x + 1

块
Blöcke

Folie 10

Ein Block fügt mehrere Anweisungen durch gleichmäßige Einrückungen zusammen.

Syntax:
Block = Statement { Statement }

  • Eine Anweisung pro Zeile
  • Die Anweisungen müssen gleich eingerückt sein

Wirkung:

  • Die Anweisungen im Block werden in der Reihenfolge des Aufschreibens hintereinander ausgeführt.

Block 块: 几条缩进相同的语句组成一组, 每行一条. 执行时按书写顺序依次执行.

Python 用缩进表示块 (别的语言用 { }), 所以缩进不是排版习惯, 而是语法的一部分: 缩进不一致会报 IndentationError.

Folie 11

Beispiel: Ausführung der Anweisungen eines Blocks

σ0 = []
kontostand = 160 # Initialer Kontostand
σ1 = [(kontostand,160,int)]
abhebe_gebühr = 3.95
σ2 = [(kontostand,160,int),(abhebe_gebühr,3.95,float)]
kontostand = kontostand - abhebe_gebühr
σ3 = [(kontostand,156.05,float),(abhebe_gebühr,3.95,float)]
kontostand = kontostand - 100 # Abheben von 100 €
σ4 = [(kontostand,56.05,float),(abhebe_gebühr,3.95,float)]

四条语句, 每条执行后写出状态 (σ 那几行不是代码, 是注解):

  • σ0 = []: 开始时没有变量.
  • 第 3 条: 160 (int) − 3.95 (float), int 被自动转成 float, 结果 156.05, kontostand 的类型从 int 变成了 float.
  • 第 4 条: 156.05 − 100 = 56.05. abhebe_gebühr 一直不变.

幻灯片小错 (浮点精度): 在 Python 里实际执行这四行, 最后 kontostand 的值是 56.05000000000001, 不是精确的 56.05 (3.95 在二进制里只能近似存储, 见第 3 章 Folie 17). 幻灯片写的 56.05 是数学上的值. 写状态时一般按数学值写, 但程序 print 出来会看到这个误差. 处理钱时通常用整数 (分) 或 decimal 模块. 

>>> kontostand = 160
>>> abhebe_gebühr = 3.95
>>> kontostand = kontostand - abhebe_gebühr
>>> kontostand = kontostand - 100
>>> kontostand
56.05000000000001
Folie 12

Ausführen von Blöcken

Der durch einen Block bewirkte Zustandsübergang erfolgt also durch Hintereinanderausführung der Zustandsübergänge der einzelnen Anweisungen.

Allgemein: Die Ausführung eines Blocks

σ0
Statement 1
  ⋮
Statement n
σn

setzt sich aus der Ausführung der Statements zusammen

σi Statement i+1 σi+1 für alle i = 0, …, n − 1

执行一个块 = 依次执行其中每条语句. 第 i+1 条语句从状态 σi 出发, 得到 σi+1; 下一条再从 σi+1 出发. 整个块把 σ0 变成 σn.

条件语句
Fallunterscheidungen (Bedingte Anweisung)

Folie 13

Syntax:

Statement   = Conditional|…
Block       = Statement { Statement }

Conditional = "if" Expression ":" Block
              { "elif" Expression ":" Block }
              [ "else:" Block ]

Beispiel

if x >= 0:
    y = x
else:
    y = -x

Beachte:

  • Gruppierung durch Einrückung
  • jeweils 4 Leerzeichen pro Unterblock
  • beliebig tiefe Schachtelung möglich

条件语句的语法: 一个 if 条件: 加一个块; 后面可以有任意多个 elif 条件: 加块 (花括号 = 0 次或多次); 最后可以有一个 else: 加块 (方括号 = 可选). 每个条件后面都有冒号.

例子算的是绝对值: x ≥ 0 时 y = x, 否则 y = −x.

注意: 用缩进分组, 惯例是每一层 4 个空格; 条件语句可以任意深地嵌套.

Folie 14

Beispiel:

if x >= 0:
    y = x
else:
    y = -x

Ausführung:

  • Wenn die Auswertung von x >= 0 im aktuellen Zustand den Wert True ergibt, wird y = x ausgeführt
  • Ansonsten wird y = -x ausgeführt

执行时先在当前状态下算条件. True → 执行 if 后面的块; False → 执行 else 后面的块. 两个块恰好执行一个.

例: σ = [(x, −3, int)], 条件 −3 >= 0 是 False, 执行 y = −x, 得到 [(x, −3, int), (y, 3, int)].

Folie 15

Allgemein: 4 Fälle wegen True/False und mit else/ohne else

  • Wenn Expression im Zustand σ zu True auswertet, und σ Statement1 σ′,
    dann σ if Expression: Statement1 else: Statement2 σ′
  • Wenn Expression im Zustand σ zu False auswertet, und σ Statement2 σ′,
    dann σ if Expression: Statement1 else: Statement2 σ′
  • Wenn Expression im Zustand σ zu True auswertet, und σ Statement σ′,
    dann σ if Expression: Statement σ′
  • Wenn Expression im Zustand σ zu False auswertet,
    dann σ if Expression: Statement σ

条件语句的执行语义, 按「条件真/假」×「有/没有 else」分四种情况:

有 else没有 else
条件为 True结果是执行 Statement1 得到的 σ′结果是执行 Statement 得到的 σ′
条件为 False结果是执行 Statement2 得到的 σ′什么都不做, 状态仍是 σ

最后一种情况容易忘: 没有 else 且条件为假时, 整个 if 语句不改变状态.

Beispiele

Beispiel 1:

if kontostand >= betrag:
    kontostand = kontostand - abhebe_gebühr
    kontostand = kontostand - betrag

Beispiel 2:

if kontostand >= betrag:

else:
    kontostand = kontostand - betrag - abhebe_gebühr
    kontostand = kontostand - überzieh_gebühr
  • 例 1: 余额够时扣手续费和取款金额 (块里有两条语句); 不够时什么都不做.
  • 例 2: 余额够时扣金额和手续费; 不够时也允许取 (透支), 但除了金额和手续费, 还要扣Überziehgebühr 透支费.

kontostand = kontostand - betrag - abhebe_gebühr

判断必须放在扣款之前, 因为条件要用扣款前的余额. 如果先扣款再写 if kontostand < 0, 余额介于 betrag 和 betrag + abhebe_gebühr 之间时结果就不同了 (原程序不收透支费, 改写后会收).

Mehrere Fallunterscheidungen

Folie 18

Fallunterscheidungen können geschachtelt werden:

if konto_gesperrt:
    print("Konto gesperrt!")
else:
    if kontostand >= betrag:
        kontostand = kontostand - betrag
        kontostand -= abhebe_gebühr
        print("Abhebung erfolgreich.")
    else:

嵌套: else 的块里又是一个完整的 if-else. 逻辑: 账户被冻结 → 提示冻结; 否则再看余额够不够. 内层 if 多缩进一层 (8 个空格).

konto_gesperrt 本身就是 bool 变量, 直接当条件用, 不必写 konto_gesperrt == True.

Folie 20

Serie von Fallunterscheidungen

Beispiel: für eine Anzahl von Spielern, welche Art von Tischtennis kann gespielt werden?

if spieler <= 1:
    print("kein Spiel")
elif spieler == 2:
    print("Duell")
elif spieler == 4:
    print("Doppel oder Rundlauf")
else:

乒乓球: 1 人以下不能打; 2 人单打 (Duell); 4 人双打或「转圈打」(Rundlauf, 大家绕着桌子轮流击球); 其余人数转圈打.

Folie 22

While-Anweisungen

Syntax:
WhileStatement = "while" Expression ":" Block

Beispiel:

i = 0
while i < 100:
    print(i)
    i = i + 1

Ausführung:
Solange die Auswertung von Expression den Wert True ergibt, wird Block immer wieder ausgeführt.

while 循环: 只要条件为 True, 就反复执行块 (循环体). 每次执行循环体之前都重新检查条件. 例子输出 0, 1, …, 99 (每个一行), 共 100 次. i 变成 100 时条件 100 < 100 为假, 循环结束.

Folie 23

Allgemein:

  • Falls die Auswertung von Expression im Zustand σ den Wert True ergibt, σ Statement σ′ und σ′ while Expression Statement σ″, dann
    σ while Expression Statement σ″
  • Falls die Auswertung von Expression im Zustand σ den Wert False ergibt, dann σ while Expression Statement σ

while 的语义是递归定义的:

  • 条件为 True: 先执行一次循环体 (σ → σ′), 然后从 σ′ 开始再执行整个 while 语句, 最终得到 σ″. 这就是「再来一轮」.
  • 条件为 False: 什么都不做, 状态仍是 σ. 循环结束.

换句话说, while E: S 等价于 if E: S; while E: S. 如果条件永远为真, 这个递归就永远不结束 (循环不终止), 这时没有最终状态.

Folie 24

While-Anweisungen: Beispiele (1)

  • Zahlen von 0 bis 99 ausgeben 
    i = 0
while i < 100:
    print(i)
    i = i + 1

print(i)         # Abbruch wenn i == 100
  • Summe der Zahlen von 0 bis 100 
    i = 1
summe = 0

while i <= 100:
    summe = summe + i       # Zwischensumme erweitern
    i = i + 1               # i erhöhen

print(summe)                # Ausgabe: 5050
  • 第一段: 循环后再 print(i), 输出 100: 循环正是在 i 达到 100 时停下的. 循环结束后循环变量保留最后的值.
  • 第二段: 求 1 + 2 + … + 100 = 5050 (高斯公式 100·101/2). summe 是累加器: 先设 0, 每轮加上当前的 i. 标题写「von 0 bis 100」, 代码从 1 开始, 加不加 0 结果一样.

手算前几轮的状态: (i, summe) = (1, 0) → (2, 1) → (3, 3) → (4, 6) → … → (101, 5050), 此时 101 <= 100 为假, 结束.

怎样设计 while 循环
Entwurf von While-Schleifen

Folie 26

Methodische Richtlinien

  1. Bestimmung der Anfangswerte der Variablen vor Eintritt in die While-Anweisung
  2. Bestimmung der Schleifenbedingung
  3. Formulierung des Schleifenrumpfes
  4. Prüfen, dass die Schleifenbedingung nach endlich vielen Ausführungen des Rumpfes nicht mehr erfüllt ist.
    Anderenfalls terminiert die While-Anweisung nicht!
x = 352
digitSum = 0

while x > 0:            # Terminiert NICHT!
    digitSum = digitSum + x % 10

写 while 循环的四步:

  1. 确定进入循环前各变量的初始值;
  2. 确定Schleifenbedingung 循环条件;
  3. 写Schleifenrumpf 循环体;
  4. 检查终止性: 循环体执行有限次后, 条件一定会变假. 否则循环不终止 (死循环).

反例: 循环体里忘了 x = x // 10, x 永远是 352, 条件永远为真, 程序永远不停 (在 Thonny 里要按停止按钮, 终端里按 Ctrl+C).

检查终止性的常用方法: 找一个每轮都严格变小、又不能无限变小的量. 这里是 x: 每轮整除 10 后严格变小, 而且始终 ≥ 0.

Folie 27

Beispiel: Fakultät einer Zahl

Fakultät n! = 1 · 2 · 3 · … · n für n ≥ 1 und 0! = 1

Entwurf eines Programms: while-Anweisung:

  1. Variablen und Anfangswerte:
    Verwende Variablen i zum Zählen (initial 1), factorial für das Ergebnis (initial 1), und n für die Zahl n.
  2. Schleifenbedingung: Zähler ist noch nicht größer als n, d.h. i <= n.
  3. Schleifenrumpf: Multipliziere Ergebnis mit dem Zähler und erhöhe den Zähler: 
    factorial = factorial * i
i += 1
  4. Terminiert die Schleife? Ja, denn i wird in jedem Durchlauf erhöht und n verändert sich nicht.
Folie 28

Beispiel: Fakultät einer Zahl

n = 5
i = 1
factorial = 1

while i <= n:
    factorial = factorial * i
    i += 1

print(factorial)

Fakultät 阶乘 n! = 1·2·…·n, 规定 0! = 1. 按 Folie 26 的四步设计: 初始值 i = 1、factorial = 1 (乘法的累积变量初值是 1, 加法是 0); 条件 i <= n; 循环体乘上 i 再让 i 加 1; 终止性: i 每轮增大而 n 不变, 早晚超过 n.

n = 5 时的状态: (i, factorial) = (1, 1) → (2, 1) → (3, 2) → (4, 6) → (5, 24) → (6, 120). 输出 120.

边界: n = 0 时条件 1 <= 0 一开始就为假, 循环一次都不执行, 输出 1, 正好符合 0! = 1.

Folie 29
  • Häufige Form einer While-Schleife ist: 
    i = start # Initialisierung einer Zählervariablen
while i <= end: # Grenze fuer den Zähler
    ...
    i += 1 # konstante Änderung des Zählers (hier +1)
  • Abkürzende Schreibweise durch eine For-Anweisung: 
    for i in Bereich / Sequenz:
    ...

很多 while 循环都是同一个模式: 计数器从 start 开始, 每轮固定加 1, 到 end 为止. for 循环是这种模式的简写: for i in 范围或序列:, i 依次取范围里的每个值, 每取一个执行一次循环体. 初始化、条件、加 1 都不用自己写, 也就不会忘了写 i += 1 而陷入死循环.

For-Schleife: Beispiele (1)

Beispiel: Summe der ersten 100 Zahlen

Lösung mit while-Schleife

    summe = summe + i
    i = i + 1

  • range(a,b) bezeichnet die Sequenz von Zahlen a,a+1,...,b-1
    • a ist das erste enthaltene Element (inklusiv)
    • b ist nicht enthalten (exklusiv)

range(a, b) 产生 a, a+1, …, b−1: 包含 a, 不包含 b. 要得到 1 到 100, 必须写 range(1, 101). 两段程序都输出 5050.

只写一个参数 range(b) 时从 0 开始: range(5) = 0, 1, 2, 3, 4 (Folie 33 用到). 对应关系: while i <= end ↔ range(start, end + 1).

For-Schleife: Beispiel (4)

Im Schleifenrumpf einer For-Anweisung kann selbst wieder eine For-Anweisung stehen. Man spricht von geschachteltem For, bzw. allgemein von geschachtelten Schleifen.

n = 5
for i in range(n):
    for j in range(i):
        print("*")

    print() # Zeilenvorschub

嵌套循环: 外层每走一轮, 内层就完整地走一遍. 外层 i = 0…4; 内层 j 走 i 次, 每次输出一个 *; 内层结束后 print() 输出一个换行 (它和内层 for 对齐, 属于外层循环体).

本意是打印一个三角形: 第 i 行有 i 个星号.

幻灯片错误: print("*") 每次调用都会自动换行, 所以星号不会排在同一行, 而是每个星号单独一行, 每组之间再隔一个空行. 实际输出 (Python 3.15): 

*

*
*

*
*
*

*
*
*
*

要打出三角形, 内层必须写 print("*", end=""): 参数 end="" 让 print 结尾不换行. 改正后的输出是一个空行, 然后 *、**、***、**** 各占一行 (i = 0 那一行没有星号, 所以第一行是空的).

For-Schleife: Beispiel (5)

  • In Python wird die for-Schleife zur Iteration über einer Sequenz von Objekten verwendet.
  • Beispiele für Seqenzen sind Ranges, Zeichenketten, Listen und Tupel (werden später detailliert betrachtet).

    print(character)

Python 的 for 其实是「对一个序列里的每个元素做一次」. range 只是序列的一种; 字符串、列表、元组也是序列.

  • 遍历字符串: character 依次是 H, a, l, l, o, 空格, W, e, l, t, !, 每个字符一行, 共 11 行 (空格那一行看起来是空的).
  • 遍历列表: 依次输出 Java, C++, Perl, Python.

循环变量名可以随便起, 起成有意义的名字 (character、language) 程序更好读.

原文笔误: 「Seqenzen」少了 u, 应为「Sequenzen」.

Folie 35

For-Schleife: Beispiel (6)

Beispiel: Quersumme einer Zahl berechnen

x = 352
digitSum = 0
while x > 0:
    digitSum += x % 10
    x = x // 10
print(digitSum)
x = 352
digitSum = 0
for ziffer in str(x):
    digitSum += int(ziffer)

print(digitSum)

另一种求各位数字之和的思路: 先用 str(x) 把数变成字符串 "352", 再遍历它的每个字符 "3"、"5"、"2", 用 int() 转回数字相加. 两边都输出 10.

右边的版本不用想 % 和 // 的技巧, 但要注意 int(ziffer) 必不可少: 字符串 "3" 不能直接和整数相加.

Terminierung von for-Schleifen

for 循环会不会不终止? 对 range、字符串、元组这类有限序列遍历时, for 一定终止: 元素个数在开始时就确定了, 循环体里改循环变量 i 也不影响下一轮取的值. 

>>> for i in range(3):
...     print(i)
...     i = 100
...
0
1
2

(遍历一个列表时在循环体里不断往这个列表里追加元素, 才可能停不下来; 列表在后面的章节讲.)

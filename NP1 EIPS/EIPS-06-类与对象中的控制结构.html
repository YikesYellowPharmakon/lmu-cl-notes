Folie 9

Klasse für Linien (benutzt Point)

from math import *

class Line:

    def __init__(self,s,e):
        self.start = s
        self.end = e

    def move(self, dx, dy):
        self.start.move(dx, dy)
        self.end.move(dx, dy)

    def length(self):
        diffX = abs(self.start.x - self.end.x)
        diffY = abs(self.start.y - self.end.y)
        return sqrt(diffX * diffX + diffY * diffY)

第 5 章 Folie 33 的 Line 类, length 写得更紧凑: 不再先存 startX、endX 等中间变量, 直接在 abs 里写 self.start.x - self.end.x. 结果相同.

Folie 12

Die Anweisungen

q  = Point(0,0)
i  = 3
p  = Point(1,i)
b  = False
ln = Line(p,q)

führen zu folgendem Zustand

逐条执行, 画出状态:

  1. q = Point(0,0): 堆上创建 Point (x=0, y=0), 栈里 q 指向它.
  2. i = 3: 栈里 i = 3, int.
  3. p = Point(1,i): 实际参数 i 先求值得 3, 堆上创建 Point (x=1, y=3), p 指向它.
  4. b = False: 栈里 b = False, bool.
  5. ln = Line(p,q): 堆上创建 Line, 它的 start 存 p 的值 (指向 Point(1,3) 的引用), end 存 q 的值 (指向 Point(0,0)). ln 指向这个 Line.

关键: Line 里存的不是两个点的副本, 而是指向同样那两个对象的引用. 图里 start 和 p 的箭头指向同一个框.

读图: 本章的状态图在栈里写「值, 类型」(3,int、False,bool); 类类型的变量只画箭头.

Folie 13

Zusammenfassung: Zustand mit Zeigerdarstellung

  • Die Programmausführung zur Laufzeit wird beschrieben durch
    • einem Stack σ für die globalen und lokalen Variablen und
    • einem Heap η für die aktuell existierenden Objekte

Beachte: Der Attributwert eines Objekts kann selbst wieder ein Verweis auf ein (anderes) Objekt sein.

总结: 程序运行时的状态 = 栈 σ (全局变量和局部变量) + 堆 η (现存的对象). 栈里变量的排列顺序无所谓. 对象的属性值也可以是指向别的对象的引用 (Line 的 start、end).

原文语法小错: 「beschrieben durch einem Stack … und einem Heap」, durch 支配第四格, 应为「durch einen Stack … und einen Heap」.

Speicherdarstellung mit Adressen

同一个状态的地址表示法: 栈里 ln 存「0x345, Line」, p 存「0x123, Point」, q 存「0x234, Point」; 堆上每个对象标着自己的地址, Line 的 start=0x123、end=0x234. 箭头就是这些地址的图形写法.

Aliasing

Folie 17

Aliasing = zwei Variablen/Zeiger auf das selbe Objekt

Die folgenden Zuweisungen auf dem Zustand der vorherigen Folie

q = p // Aliasing!
q.x = q.x + 1
b = (p.x == 2)

führen zu folgendem Zustand

在 Folie 12 的状态上执行:

  1. q = p: q 改为指向 p 所指的 Point(1,3). 现在两个变量指向同一个对象, 这就是 Aliasing 别名. 原来 q 指向的 Point(0,0) 还被 ln.end 引用着.
  2. q.x = q.x + 1: 那个共同的对象的 x 从 1 变成 2.
  3. b = (p.x == 2): p.x 现在也是 2 (同一个对象), 所以 b = True.

幻灯片错误: 代码 q = p // Aliasing! 里又用了 // 当注释 (第 3 章 Folie 51 同样的问题). Python 的注释是 #; 写 // 会被当成整除运算符, 这一行是 SyntaxError. 应写 q = p # Aliasing!.

Folie 18

Aliasing (1)

Aliasing = Vorhandensein mehrerer Variablen, die auf den gleichen Speicherort verweisen.

Im Beispiel q = p sind p und q Referenzen auf dasselbe Objekt.

Problematik:

  • Fehlerquelle, da Änderungen über eine Variable z.B. q.x = q.x+1 auch zu Änderungen für die andere Variable führen (auch p.x wurde um 1 inkrementiert), ohne dass man es richtig sieht.
  • Programme, die Aliasing verwenden sind oft schlecht nachvollziehbar.

Aliasing 别名: 多个变量指向同一块内存 (同一个对象).

问题: 它是常见的错误来源. 通过一个变量做的修改, 从另一个变量也看得到, 但代码里看不出来: 读 q.x = q.x + 1 这一行, 很难想到 p.x 也变了. 大量使用别名的程序难以理解.

需要真正的副本时, 要新建一个对象: q = Point(p.x, p.y).

Folie 19

Aliasing (2)

Beachte, dass bei Grunddatentypen in Python kein Aliasing auftritt:

i = 3
j = i
i = i+1
print("i=" + str(i))
print("j=" + str(j))

Bei Grunddaten werden die Werte der Variablen direkt im Zustand σ gespeichert.

输出 i=4 和 j=3 (实际运行): 改 i 不影响 j. 按本课的模型, 基本类型的值直接存在栈里, j = i 是把数值 3 复制给 j, 两个变量各有一份.

Python 的实际机制: 整数在 Python 里其实也是对象, j = i 之后 i 和 j 确实指向同一个整数对象 3. 但整数是不可变的 (immutable): 没有任何操作能改变 3 这个对象本身. i = i + 1 是创建 (或取得) 一个新对象 4 并让 i 改指向它, j 仍指向 3. 所以从效果上看, 对 int、float、bool、str 这些不可变类型, 别名永远不会造成问题, 本课的「直接存值」模型和实际效果一致. 对可变对象 (自己定义的类、list 等) 就要当心.

垃圾
Datenmüll

Folie 20

Die folgende Zuweisung auf dem Zustand von vorher

ln.end = p

führt zu folgendem Zustand

  • Das Objekt wird nicht mehr referenziert und ist daher Müll (Garbage).
  • Es wird von der automatischen Speicherverwaltung (Garbage Collector) gelöscht.

在 Folie 17 的状态上执行 ln.end = p: Line 的 end 改为指向 Point(2,3). 原来的 Point(0,0) 之前只剩 ln.end 指着它 (q 在 Folie 17 已经改指了), 现在没有任何变量或属性引用它, 程序再也访问不到它, 它就成了 Müll 垃圾 (Garbage).

Garbage Collector 垃圾回收器是 Python 的自动内存管理: 它会自动删除垃圾对象, 释放内存. 程序员不需要 (也不能) 手动释放对象. C 语言要手动 free, 忘了就会内存泄漏.

现在 ln.start 和 ln.end 指向同一个点, 线段长度是 0.

Folie 23

Typ und Auswertung der neuen Ausdrücke

  • Ein Ausdruck ist (wie bisher) typkorrekt, wenn bei der Auswertung kein Typfehler auftritt.
  • Die Auswertung eines Ausdrucks e erfolgt (jetzt) unter einem Stack (σ) und einem Heap (η), d.h. wir berechnen e =(σ,η) …
  • Der Attributzugriff mit . und der Methodenaufruf mit . haben die höchste Präzedenz 15.

表达式类型正确 = 求值时不出现类型错误. 求值在栈 σ 和堆 η 下进行. 点号优先级最高 (15).

注意: 第 5 章 Folie 50 的定义是「能给它定出一个类型」, 这里换成「求值时没有类型错误」. 前者是静态 (运行前) 的看法, 后者是 Python 这种动态类型语言的实际情况 (类型错误要运行到才发现). 两种说法对本课的例子结论相同.

Objekterzeugungsausdruck

Folie 24 
ClassInstanceCreation = ClassType "(" [ ActualParameters ] ")"

Ein Objekterzeugungsausdruck hat also die Form C(a1,...,an)

  • C muss eine deklarierte Klasse sein.
  • Wenn die aktuelle Parameterliste nicht leer ist, muss in der Klasse C der Konstruktor __init__ definiert sein mit n formalen Parametern
    __init__(self, x1​,..., xn): body
  • Die aktuellen Parameter a1​,…,an​ sind Ausdrücke.
  • Der Ausdruck C(a1,...,an) hat dann den Typ C

第 5 章 Folie 56 的 Python 版: 有参数时类里必须有 __init__(self, x1, …, xn), 参数个数 n 要对上 (self 不算). 表达式的类型是 C.

Folie 27

Objekterzeugungsausdruck: Beispiele und Auswertung (2)

Mit der Zuweisung p = Point(x0,y0) wird

  1. ein neues Objekt der Klasse Point erzeugt und auf den Heap gelegt
  2. die Felder des Objekts mit den Werten von x0 und y0 initialisiert
  3. eine Referenz auf das neu erzeugte Objekt als Ergebniswert geliefert

Mit der Zuweisung p1 = Point(1,2) wird der Rumpf des benutzerdefinierten Konstruktors ausgeführt und damit den Attributen x und y des neu erzeugten Objekts die Werte 1 und 2 zugewiesen.

同第 5 章 Folie 59: 在堆上创建对象 → 执行 __init__ 初始化 → 返回指向它的引用.

Folie 28

Objekterzeugungsanweisung

Syntax:

Statement             = ...
                       |ClassInstanceCreation

ClassInstanceCreation = ClassType "(" [ ActualParameters ] ")"

Eine Objekterzeugungsanweisung hat also die Form

C(a1,...,an)

wobei C(a1,...,an) ein Objekterzeugungsausdruck ist.

创建对象也可以单独写成一条语句: 一行只写 Point(1, 2), 不赋值给任何变量. 对象被创建、初始化, 但引用没有存下来, 所以它马上就是垃圾. 只有 __init__ 有别的效果 (例如 print) 时这样写才有意义.

Folie 29

Wirkung der Objekterzeugungsanweisung

C(a1,...,an) hat folgende Wirkung

  1. Ein Objekt der Klasse C wird erzeugt und auf den Heap gelegt.
  2. Die Referenz auf das Objekt wird bereitgestellt.

Falls ein benutzerdefinierter Konstruktor aufgerufen wurde, erfolgt vor Schritt 2:

  1. Die Werte der aktuellen Parameter a1​,...,an​ werden berechnet,
  2. Eine lokale Variable self mit Typ C wird angelegt und mit der Referenz auf das neue Objekt initialisiert und lokale Variablen für die formalen Parameter x1​,...,xn​ des Konstruktor werden angelegt und mit den erhaltenen Werten für a1​,...,an​ initialisiert.
  3. Der Rumpf des Konstruktors wird als Block ausgeführt.
  4. Die lokalen Variablen self, x1​,...,xn​ werden aus dem Stack σ genommen.

创建对象的精确执行规则 (第 5 章说「留到第 6 章」的那个):

  1. 在堆上创建一个 C 类的新对象 (此时还没有属性).
  2. 如果类里有 __init__, 在交出引用之前先做四步:
    1. 依次算出实际参数的值;
    2. 在栈上新建局部变量 self (指向新对象) 和形式参数 x1​…xn​ (值为刚算出的实参值);
    3. 把 __init__ 的函数体当作块执行 (通常是 self.x = x0 之类, 给新对象添加属性);
    4. 把 self 和 x1​…xn​ 从栈上删掉.
  3. 交出指向新对象的引用.

例: 执行 p = Point(1, i) (i = 3) 时, 栈上临时出现 self、x0 = 1、y0 = 3; 执行完 self.x = x0、self.y = y0 后这三个变量消失, 只剩堆上的 Point(1, 3) 和 p 的箭头. 和 Folie 37–41 的方法调用几乎一样.

Folie 36

Die Methodenaufrufanweisung

Syntax:

Statement  = ...
            |MethodCall
MethodCall = Expression "." Identifier "(" [ ActualParameters ] ")"
  • Eine Methodenaufrufanweisung hat also die Form e.m(a1,...,an)
  • Der Ausdruck e muss einen Klassentyp haben und der Identifier m muss ein Name einer Methode der Klasse (oder einer Oberklasse, vgl. später) sein:
    m(self, x1​,..., xn) body
  • Die aktuellen Parameter a1​,...,an​ sind Ausdrücke, die in Anzahl zu den formalen Parametern der Methodendeklaration passen müssen.

Beispiel: Sei p eine Variable die Point Objekt referenziert
Methodenaufrufanweisung: p.move(10,15)

方法调用语句: 把方法调用单独写成一行, 例如 p.move(10, 15). 类型规则和方法调用表达式相同. 这类调用的意义在于它改变状态 (move 没有返回值).

Folie 37

Die Wirkung der Methodenaufrufanweisung

e.m(a1,...,an) hat folgende Wirkung:
Sei e ein Ausdruck mit Klassentyp C.

  1. e wird im aktuellen Zustand ausgewertet. Falls der Wert None ist, erfolgt ein Laufzeitfehler, anderenfalls sei ref die erhaltene Objektreferenz.
  2. Berechne die Werte von a1​ bis an​ nacheinander. Seien w1​,…,wn​ die erhaltene Werte.
  3. Lege lokale Variable self an, die mit ref initialisiert wird, und lege lokale Variablen x1​,...,xn​ für die formalen Parameter an, die mit w1​,…,wn​ initialisiert werden.
  4. Der Rumpf der Methode wird als Block ausgeführt.
  5. Die lokalen Variablen self, x1​,...,xn​ werden aus dem Stack σ entfernt.

方法调用 e.m(a1, …, an) 的执行规则 (考试重点):

  1. 求 e 的值. 是 None → 运行时错误; 否则得到对象引用 ref.
  2. 依次求出实参的值 w1…wn.
  3. 在栈上新建局部变量: self = ref, x1 = w1, …, xn = wn. 这一步就是参数传递: 把实参的值复制给形参.
  4. 把方法体当作块执行.
  5. 从栈上删掉 self 和 x1…xn.

重点: 传进去的是值. 对基本类型就是数值本身; 对对象就是引用的副本. 所以方法里通过 self 或对象形参修改对象的属性, 调用者能看到 (同一个对象); 但在方法里给形参重新赋值, 只改了局部变量, 调用者看不到 (见 Folie 42).

按 Folie 37 的五步执行 p.move(i, 2+2):

  1. 求 p: 得到指向 Point(1, 3) 的引用 ref.
  2. 求实参: i → 2, 2+2 → 4.
  3. 栈上新建 self = ref (箭头指向同一个 Point)、dx = 2、dy = 4 (Folie 39).
  4. 执行方法体: self.x = 1 + 2 = 3, self.y = 3 + 4 = 7 (Folie 40).
  5. 删掉 self、dx、dy (Folie 41). 栈恢复成原来的样子 (i、p), 但堆上的对象已经变成 (3, 7).

结论: 方法通过 self 修改对象, 修改在方法结束后仍然存在, 因为对象在堆上, 不随局部变量删除.

Folie 42

Was wird ausgegeben?

class Point:
   def __init__(self, x0, y0):
      self.x = x0
      self.y = y0
   def update(self, p):
      p = self
p1 = Point(1,2)
p2 = Point(0,0)
p2.update(p1)
print(p1 == p2)

答案: False (实际运行). 按 Folie 37: 调用 p2.update(p1) 时, 栈上新建 self = p2 的引用、形参 p = p1 的引用 (副本). 方法体 p = self 只是让局部变量 p 改指向 p2 的对象, 栈外的 p1 完全不受影响, 两个对象也都没有被修改. 方法结束, 局部变量 p 被删掉. 所以 p1 和 p2 仍指向两个不同的对象, p1 == p2 是 False; p1.x 仍是 1.

易错: 以为「p = self」会让外面的 p1 也变成 p2. 给形参重新赋值永远不影响调用者的变量; 只有修改形参所指对象的属性 (如 p.x = self.x) 才会被调用者看到.

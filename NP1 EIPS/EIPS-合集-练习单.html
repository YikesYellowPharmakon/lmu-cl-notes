Aufgabe 1-1 · Arbeiten mit Python mit IDE (Thonny) · Präsenz

In dieser Aufgabe sollen Sie die Vorteile einer IDE (Integrated Development Environment) wie Thonny gegenüber der Benutzung eines einfachen Editors erfahren. Um diese Aufgabe bearbeiten zu können, müssen Sie Python und Thonny installiert haben, wie in der Installationsanweisung für Ihre Plattform (Windows oder Mac) besprochen wird.

翻译: 这张练习单在 10 月 16 日和 19 日的小组练习课上讨论. Aufgabe 1-1 是课堂题 (Präsenz, 在练习课上一起做, 不用交). 目的是体会 IDE 集成开发环境比普通文本编辑器好在哪里: IDE 会帮你标出错误、给出提示、直接运行程序. 做题前要按安装说明装好 Python 和 Thonny.

四个小题考的是一件事: 语法错误 (Python 读不懂, 程序根本跑不起来) 和语义错误 (程序能跑, 但结果不是你想要的) 的区别, 以及 Thonny 怎样把语法错误指给你看. 这就是 EIPS 01 讲的 syntaktische vs. semantische Korrektheit.

出发点: 安装说明里的程序只有一行: 

print("Hallo Welt!")

Thonny 界面用语对照: 练习单用德语界面的叫法. 上半部分是 Editor 编辑器, 写程序文件; 下半部分是 Kommandozeile (英文界面叫 Shell, 中文界面叫「Shell」或「命令行」), 运行结果和报错都显示在这里.

a) 让程序问候你自己

Aufgabe 1-1 a)

Verändern Sie das Programm aus der Installationsanleitung Windows/Mac in Thonny so, dass Sie selbst mit Ihrem Namen begrüßt werden. Speichern Sie die Datei ab. Führen Sie das Programm erneut in Thonny aus. Was wird in der Kommandozeile ausgegeben und warum?

翻译: 在 Thonny 里修改安装说明中的程序, 让它用你的名字问候你. 保存文件, 再在 Thonny 里运行. 命令行里输出了什么? 为什么?

思路: 只改引号里的文字. 保存后再运行, 看 Shell 里出现的每一行分别是谁写的、为什么会出现.

答案 (先自己做再看)

做法: 只改引号里的文字. 

print("Hallo Hanyang!")

保存 (⌘S), 点绿色运行按钮或按 F5. 命令行 (Shell) 里显示: 

>>> %Run hallo.py
Hallo Hanyang!

为什么:

  • 第一行 %Run hallo.py 是 Thonny 自己写的: 它表示「现在运行刚保存的这个文件」. 所以要先保存, Thonny 运行的是磁盘上的文件.
  • 第二行是程序的输出: print(…) 把括号里的内容显示出来. 引号里的文字是一个字符串 (String), Python 原样输出, 不带引号.

易错: 引号要用英文直引号 ", 不能用中文输入法的「“ ”」, 否则会报 SyntaxError: invalid character '“' (U+201C).

b) 去掉引号: 语法错误

Aufgabe 1-1 b)

Stellen Sie wieder den Ursprungszustand Ihres Programms her, d.h. das Programm soll nun wieder Hallo Welt! ausgeben. Verändern Sie dann Ihr Programm, indem Sie die Anführungszeichen weglassen, d.h. Ihr Programm sollte nun folgendermaßen aussehen:

1  print(Hallo Welt!)

Wie und wo stellt Thonny überall dar, dass in Ihrem Programm ein Fehler enthalten ist?

翻译: 先把程序改回输出 Hallo Welt!, 再把引号去掉. Thonny 在哪些地方、怎样显示程序里有错误?

思路: 没有引号时, Python 会把 Hallo 和 Welt 理解成什么? 分别看 Shell、编辑器和助手面板这三处.

答案 (先自己做再看)

实际运行结果: 

  File "hallo.py", line 1
    print(Hallo Welt!)
          ^^^^^^^^^^
SyntaxError: invalid syntax. Perhaps you forgot a comma?

Thonny 显示错误的几个地方:

  1. 命令行 (Shell): 红色的错误信息, 写明错误类型 SyntaxError、出错的行号 (line 1), 并用 ^^^^ 指出出错的位置. 行号是链接, 点一下会跳到编辑器里那一行.
  2. 编辑器: 出错的那一行或那个位置被标记出来, 光标跳到错误附近.
  3. 助手面板 (菜单 Ansicht/View → Assistent, 中文界面「视图 → 助手」): 用较好懂的语言解释错误可能的原因, 并给出修改建议.

和普通编辑器对比: 普通编辑器什么都不提示, 只有运行时才在终端里看到一段报错, 还得自己去找是哪一行. 这就是题目说的「IDE 的优势」.

为什么是语法错误: 没有引号时, Python 把 Hallo 和 Welt 当作两个变量名. 两个名字之间什么都没有, 后面还跟着一个 !, 不符合 Python 的语法规则, 所以程序一行都没执行就停了. 报错提示「是不是忘了逗号?」, 是因为 Python 猜你可能想写 print(Hallo, Welt).

如果只写 print(Hallo) (一个词、没有感叹号), 语法就是对的, 错误要等到运行时才出现: NameError: name 'Hallo' is not defined, 因为没有叫 Hallo 的变量. 语法错误在程序开始前就被发现; 运行时错误要执行到那一行才出现.

c) Welt 写成 Wlt: Python 发现不了的错误

Aufgabe 1-1 c)

Fügen Sie die Anführungszeichen wieder in das Programm ein, ersetzen Sie jetzt aber das Wort Welt durch Wlt, d.h. Ihr Programm sollte folgendermaßen aussehen:

1  print("Hallo Wlt!")

Kann Python hier einen Fehler finden? Erklären Sie Ihre Antwort.

翻译: 把引号加回来, 但把 Welt 换成 Wlt. Python 能找到这里的错误吗? 解释原因.

思路: Python 检查的是程序是否符合语法. 它会去检查字符串里写的内容吗?

答案 (先自己做再看)

答案: 不能. 程序正常运行, 输出: 

Hallo Wlt!

原因: 引号里的内容是字符串, 对 Python 来说只是一串字符, 它不检查字符串里写的是什么. print("…") 的语法完全正确, 所以没有报错. 拼错单词是语义错误: 程序语法对、能运行, 但做的事 (输出 Wlt) 不是我们想要的 (输出 Welt).

这正好对应 EIPS 01 的结论: Syntaktisch korrekte Programme sind häufig semantisch nicht korrekt, 语法正确的程序常常语义不正确. 语义错误只能靠人检查或测试 (把实际输出和预期比较) 来发现, IDE 帮不了你.

d) 加换行: 三个程序, 三种结果

Aufgabe 1-1 d)

Stellen Sie wieder den Ursprungszustand Ihres Programms her, d.h. das Programm soll nun wieder Hallo Welt! ausgeben. Fügen Sie anschließend entsprechend der untenstehenden drei Programme Zeilenumbrüch ein und führen das jeweilige Programm aus. Ihr Programm sollte für die einzelnen Versuche folgendermaßen aussehen:

1  print
2  ("Hallo Welt!")
1  print(
2  "Hallo Welt!")
1  print(
2  "Hallo
3  Welt!")

Können Sie Ihr Programm jetzt noch ausführen? Erklären Sie Ihre Antwort!

翻译: 把程序恢复原样, 然后按下面三个版本分别加换行, 各运行一次. 程序还能运行吗? 解释原因.

思路: Python 在什么时候认为一条语句结束了? 括号里的换行、字符串里的换行, 有什么不同? 分清「提到一个函数」和「调用一个函数」.

答案 (先自己做再看)

实际运行结果:

版本能运行吗输出
① print 和 ("Hallo Welt!") 分两行能运行, 但什么都不输出 (空)
② 换行在 ( 后面能, 正常Hallo Welt!
③ 换行在字符串中间不能, 语法错误SyntaxError: unterminated string literal (detected at line 2)

为什么: 关键规则是: 在 Python 里, 换行就是一条语句的结束, 除非还在括号里面.

  • ①: 第 1 行的 print 后面没有括号, 换行就结束了这条语句. 这一行只是「提到」print 这个函数, 并没有调用它. 第 2 行 ("Hallo Welt!") 是另一条独立的语句: 一个用括号括起来的字符串, 算出来之后就被丢掉, 不会打印. 所以程序不报错, 但什么也不输出. 这又是一个语义错误: 语法对, 结果不对.
  • ②: 换行发生在括号里面. Python 看到 ( 还没有配对的 ), 就知道语句没结束, 会把下一行接上来, 等同于原来的一行. 所以结果正常. 长的函数调用常常这样拆成几行.
  • ③: 普通字符串 (一对 ") 必须在同一行内结束. 第 2 行的 "Hallo 后面直接换行, 字符串没有闭合, Python 报「未结束的字符串」, 程序一行都不执行. 在括号里也不行, 因为「括号内可以换行」只适用于字符串之外的地方.

易错: ① 最容易答错, 很多人以为会报错. 要分清「提到一个函数」 (print) 和「调用一个函数」 (print(...)): 只有带上紧跟的括号才是调用.

如果真的想在字符串里换行, 有两种正确写法: 

print("Hallo\nWelt!")       # \n 是换行符
print("""Hallo
Welt!""")                     # 三引号字符串可以跨行

两种都输出两行: Hallo 和 Welt! (已实际运行确认).

在 Thonny 的 Shell (交互模式 >>>) 里逐行输入版本 ① 会看到不同的结果: 输入 print 会显示 <built-in function print>, 再输入 ("Hallo Welt!") 会显示 'Hallo Welt!' (带引号). 这是因为交互模式会自动显示每条表达式的值, 而运行脚本文件时不会.

原文笔误: 「Fügen Sie anschließend … Zeilenumbrüch ein」少了词尾, 应为「Zeilenumbrüche」 (复数第四格). 另外练习单开头写「Installationsanweisung」, a) 里又写「Installationsanleitung」, 前后用词不一致, 指的是同一份文件 (文件名是 Installationsanweisung_mac.pdf, 文件里的标题是 Installationsanleitung Mac OS), 不影响题意.

Multiple-Choice-Frage

Was kann mit einer EBNF-Grammatik nicht beschrieben werden?

  1. syntaktisch korrekte Worte
  2. sinnvolle Worte

翻译: EBNF 文法用来描述一种语言里哪些词 (和句子) 是合法的: 可以是德语, 也可以是德语里的特定部分 (回文、时刻), 也可以是编程语言. 问题: 哪一样不能用 EBNF 文法描述? a) 语法正确的词; b) 有意义的词.

思路: 回想第 2 章「语法」和「语义」的区分. 文法规则只看符号怎样排列, 它能不能判断一句话「说得通」?

答案 (先自己做再看)

答案: b) sinnvolle Worte, 有意义的词.

EBNF 只描述语法: 哪些符号串按规则排得对. 「有没有意义」属于语义, 文法管不了. 例: 按时刻文法, 「23:59」是合法的; 但文法不知道「23:59 是一天的最后一分钟」. 同理, Python 的文法接受 print("Hallo Wlt!"), 却发现不了 Wlt 是拼错的 (练习单 1 c). 德语里「Der Tisch schläft grün」语法通顺, 意思却说不通.

2. EBNF 文法由什么组成
EBNF-Grammatik: Wie?

Zentralübung · Folie 6
  • Terminalsymbole: „Buchstaben“ in der Sprache
  • Nichtterminalsymbole: Hilfsbegriffe, um mehrere „Buchstaben“ oder „Buchstabenfolgen“ der Sprache zusammenzufassen
  • Regeln der Form A = Ausdruck
    • A: Nichtterminalsymbol
    • Ausdruck: Nichtterminal- und Terminalsymbole verbunden durch Operatoren
      • E1 E2
      • E1 | E2
      • [E1] (= ein E1 oder kein E1)
      • {E1} (= beliebig viele E1, auch kein E1)
  • Startsymbol

翻译 (第 2 章的复习):

  • Terminalsymbol 终结符: 语言里真正出现的「字母」, 在 EBNF 里写在引号中, 如 "0"、":".
  • Nichtterminalsymbol 非终结符: 辅助概念, 把几个字母或字母串归成一类, 如 Stunde (小时)、Minute (分钟). 它们最终都要被替换掉, 不会出现在推导出的词里.
  • 规则 A = 表达式: 左边一个非终结符, 右边是非终结符和终结符用运算符连起来: 并列 E1 E2 (先 E1 后 E2); 选择 E1 | E2 (二选一); 可选 [E1] (有一个 E1 或没有); 重复 {E1} (任意多个 E1, 也可以一个都没有).
  • Startsymbol 起始符: 推导从它开始, 这里是 Uhrzeit.

3. 写出时刻的文法 (I)
EBNF-Grammatik: Beispiel für Uhrzeiten (I)

Zentralübung · Folie 7
  • Eine Uhrzeit wird angegeben durch Angabe der Stunde, gefolgt von einem Doppelpunkt und der Angabe der Minuten.
  • ACHTUNG: Korrekte Uhrzeiten gehen von 00:00 bis 23:59

EBNF-Grammatik

翻译: 一个时刻由「小时、冒号、分钟」组成. 注意: 正确的时刻从 00:00 到 23:59. 写出描述它的 EBNF 文法.

思路: 先按题目的句子结构写起始规则 (小时、冒号、分钟三段并列), 再分别规定小时和分钟可以是哪些两位数. 冒号是终结符, 要加引号.

答案 (先自己做再看) 
Uhrzeit = Stunde ":" Minute
Stunde  = "00" | "01" | ... | "23"
Minute  = "00" | "01" | ... | "59"

幻灯片在这个文法上标了三处: Minute 是非终结符, "59" 是终结符; Stunde 和 Minute 的规则里, "00"、"01" 等终结符重复出现 (Doppeltes Vorkommen).

重复出现为什么是问题: 00 到 23 这 24 个两位数在两条规则里各写了一遍; 而且「…」不是 EBNF 的运算符, 严格写出来, 两条规则要列 24 + 60 = 84 个选项. 下一个版本用辅助非终结符 (只描述一位数字) 把重复的部分提出来.

核对: 用脚本列出这个文法的全部词, 共 24 × 60 = 1440 个, 正好是 00:00 到 23:59 的全部时刻.

4. 时刻的文法 (II): 用辅助非终结符
EBNF-Grammatik: Beispiel für Uhrzeiten (II)

Zentralübung · Folie 8
  • Eine Uhrzeit wird angegeben durch Angabe der Stunde, gefolgt von einem Doppelpunkt und der Angabe der Minuten.
  • ACHTUNG: Korrekte Uhrzeiten gehen von 00:00 bis 23:59

EBNF-Grammatik

翻译: 同一个任务, 题目文字和上一页完全相同. 这一版的写法不用「…」, 终结符只用一位数字.

思路: 把小时按第一位分成三种情况: 0 开头、1 开头 (第二位都可以是 0–9)、2 开头 (第二位只能是 0–3). 分钟的第一位是 0–5, 第二位是 0–9. 再为「0–3」「0–5」「0–9」各定义一个非终结符, 后一个可以引用前一个.

答案 (先自己做再看) 
Uhrzeit     = Stunde ":" Minute
Stunde      = ("0" NullBisNeun) | ("1" NullBisNeun) |
              ("2" NullBisDrei)
Minute      = NullBisFünf NullBisNeun
NullBisDrei = "0" | "1" | "2" | "3"
NullBisFünf = NullBisDrei | "4" | "5"
NullBisNeun = NullBisFünf | "6" | "7" | "8" | "9"
  • Stunde: 三个选项, 每个都用括号把「第一位 + 第二位」括成一组, 再用 | 连起来. 2 开头时第二位只能是 NullBisDrei, 所以 24–29 推不出来.
  • Minute: 第一位 0–5, 第二位 0–9, 所以 60 及以上推不出来.
  • 三个数字范围层层引用: 0–5 是「0–3 再加 4、5」, 0–9 是「0–5 再加 6–9」. 每个数字只写了一次, 没有重复.

核对: 用脚本列出这个文法的全部词, 也是正好 1440 个, 和版本 (I) 的语言完全相同: 17:49、00:00、23:59 在里面, 24:00、33:33、12:60、只写一位小时的 9:30 都不在. 两个文法不同, 描述的语言相同.

5. 计算机里用 EBNF 文法做什么
Multiple-Choice-Frage

Zentralübung · Folie 9

Wozu werden EBNF-Grammatiken im Computer verwendet?

  1. Bilden syntaktisch korrekter Programme
  2. Überprüfen syntaktisch korrekter Programme
  3. Ausführen syntaktisch korrekter Programme

翻译: 计算机里 EBNF 文法用来做什么? a) 构造语法正确的程序; b) 检查程序语法是否正确; c) 执行语法正确的程序.

思路: 想一想第 2 章开头: 编译器或解释器拿到一段程序后, 第一件事是做什么? 执行时程序「做什么」又是由什么决定的?

答案 (先自己做再看)

答案: b) 检查.

编译器和解释器用语言的文法检查一段程序能不能从起始符推导出来; 推不出来就报 SyntaxError, 程序一行都不执行 (练习单 1 b、d ③). Python 的语言参考手册就是用 EBNF 的一种变体写的 (EIPS 02 「Python 的语法定义」).

a) 也说得通: 文法规定了怎样写出合法的程序, 有的工具也会按文法自动生成测试程序. 但计算机里最主要的用途是 b. c) 不对: 执行时做什么属于语义, 文法只管形式, 不管意思 (见第 1 题).

6. 长推导: 推出 17:49
EBNF-Grammatik – Ableitung: Allgemein · Beispiel: 17:49 (lang)

  • Beginne mit Startsymbol
  • Wiederhole, bis gewünschtes Wort “da steht”:
    • Ersetze ein oder mehrere Nichtterminalsymbole durch die rechte Seite ihrer Regel und
    • Führe anschließend einen oder mehrere Operatoren aus, falls möglich
Zentralübung · Folie 11

(Grammatik (II) wie oben)

Beispiel: Ableitung einer korrekten Uhrzeit: 17:49 (lang)

翻译: 长推导: 从起始符开始, 反复做下面两种动作之一, 直到想要的词出现: 把一个或几个非终结符换成它的规则右边; 或者执行一个或几个运算符. 短推导: 每一步先替换, 然后在可能时接着执行运算符, 两种动作合在一步里. 任务: 用文法 (II) 给 17:49 写一个长推导.

思路: 长推导的每一步只能二选一: 要么是「Regel」(按规则替换), 要么是「Op |」(在选择里挑一个). 按从左到右的顺序处理: 先把 Stunde 变成 "1" "7", 再处理 Minute. 每一步都在箭头上标明做的是哪种动作.

答案 (先自己做再看)

幻灯片上的长推导 (每行左边是这一步做的动作, 用的是文法 (II)): 

Uhrzeit
Regel → Stunde ":" Minute
Regel → (("0" NullBisNeun) | ("1" NullBisNeun) |
         ("2" NullBisDrei)) ":" Minute
Op |  → "1" NullBisNeun ":" Minute
Regel → "1" (NullBisFünf | "6" | "7" | "8" | "9") ":" Minute
Op |  → "1" "7" ":" Minute
Regel → "1" "7" ":" NullBisFünf NullBisNeun
Regel → "1" "7" ":" (NullBisDrei | "4" | "5") NullBisNeun
Op |  → "1" "7" ":" "4" NullBisNeun
Regel → "1" "7" ":" "4" (NullBisFünf | "6" | "7" | "8" | "9")
Op |  → "1" "7" ":" "4" "9"
  • Regel 和 Op 严格交替出现: 每次替换出一个带 | 的括号, 下一步就用 Op 在其中选一个. 幻灯片在每一行用下划线标出下一步要替换的非终结符.
  • Minute 的规则 NullBisFünf NullBisNeun 里没有 |, 所以替换后不需要 Op, 紧接着又是一步 Regel.
  • 选 7 时直接在 NullBisNeun 的选项里挑 "7"; 选 4 和 9 时同理. 如果要选的是 0–5 中的数字, 就要先选 NullBisFünf, 再把它替换、再选一次, 推导会更长.

原文笔误: 倒数第二行写成「"4" (NullBisFünf |"6" | "7" | "8"| "9"))」, 末尾多了一个右括号, 上面已删去. 「"1" "7"":"」中间也少了一个空格.

和讲座的定义不完全一致: 这里把短推导写成「替换, 然后在可能时执行运算符」, 像是必须合并. 讲座 (EIPS 02 Folie 41) 的定义是一步里替换和/或执行运算符, 并且「Darf」约定: 可以合并, 但不必合并, 所以每个长推导也都是短推导. 考试以讲座的定义为准.

7. 哪一步只属于短推导
Multiple-Choice-Frage

Zentralübung · Folie 12

(Grammatik (II) wie oben)

Was ist ein Schritt in einer kurzen Ableitung, aber nicht in einer langen Ableitung?

  1. Stunde → ("0" NullBisNeun) | ("1" NullBisNeun) | ("2" NullBisDrei)
  2. Stunde → "1" NullBisNeun
  3. Stunde → "1" "7"

翻译: 下面哪一步可以出现在短推导里, 但不能出现在长推导里?

思路: 对每个选项数一数: 从 Stunde 到右边, 一共做了几次替换、几次运算符? 长推导一步只能做一种; 短推导一步可以「替换 + 运算符」, 但替换的只能是这一步开始时已经在那里的非终结符.

答案 (先自己做再看)

答案: b).

  • a) 只做了一次替换 (把 Stunde 换成规则右边), 没有执行运算符. 这是长推导的合法一步; 按讲座的定义也是短推导的一步. 不是答案.
  • b) 替换 Stunde 之后, 紧接着用 | 选了第二个选项: 替换 + 运算符合在一步. 长推导必须拆成两步 (见第 6 题的第 2、3 行), 所以 b) 只能出现在短推导里.
  • c) 除了 b) 的两个动作, 还把 NullBisNeun 替换掉并选了 "7". 但 NullBisNeun 是这一步中途才出现的, 一步里只能替换开始时已有的非终结符, 所以 c) 在两种推导里都不是一步, 至少要两步 (见第 8 题的短推导).

原文笔误: 这一页的文法和选项里三次写成「NullbisNeun」(小写 b), 其他地方都是 NullBisNeun. EBNF 里非终结符的名字区分大小写, 严格来说 NullbisNeun 是一个没有规则的新符号. 按上下文应为 NullBisNeun.

8. 短推导: 推出 17:49
Beispiel: Ableitung einer korrekten Uhrzeit: 17:49 (kurz)

Zentralübung · Folie 13

(Grammatik (II) wie oben)

Ableitung einer korrekten Uhrzeit: 17:49 (kurz)

翻译: 用文法 (II) 给 17:49 写一个短推导.

思路: 每一步把当前所有的非终结符同时替换, 并立刻在新出现的选择里挑好. 和第 6 题的 11 行相比, 应该只需要三步.

答案 (先自己做再看) 
Uhrzeit
Regel         → Stunde ":" Minute
Regel, Op |   → "1" NullBisNeun ":" NullBisFünf NullBisNeun
Regel, Op |   → "1" "7" ":" "4" "9"
  • 第 2 步: 同时替换 Stunde 和 Minute; Stunde 的右边有 |, 立刻选 "1" NullBisNeun; Minute 的右边没有 |, 原样写下 NullBisFünf NullBisNeun.
  • 第 3 步: 同时替换剩下的三个非终结符 (两个 NullBisNeun、一个 NullBisFünf), 在各自的选项里选 "7"、"4"、"9".

第 1 步只有替换, 没有运算符可以执行 (起始规则里没有 |), 这符合「falls möglich」.

原文笔误: 第 2 步写成「nullBisFünf」(小写 n), 应为 NullBisFünf, 上面已改正.

9. 33:33 为什么推不出来
Beispiel: Ableitung einer inkorrekten Uhrzeit: 33:33

(Grammatik (II) wie oben)

Ableitung einer inkorrekten Uhrzeit: 33:33

翻译: 试着给不正确的时刻 33:33 写推导.

思路: 第一步照样得到 Stunde ":" Minute. 接下来 Stunde 的三个选项, 第一位分别是什么? 有没有哪个能变出开头的 "3"?

答案 (先自己做再看) 
Uhrzeit
Regel → Stunde ":" Minute
Regel → ???

keine Regel, um "3" an erster Stelle der Stunde abzuleiten → 33:33 ist nicht ableitbar → 33:33 ist keine korrekte Uhrzeit.

讲解: Stunde 的三个选项都以终结符 "0"、"1" 或 "2" 开头, 没有任何规则能在小时的第一位产生 "3", 所以 33:33 推不出来. 推不出来, 就说明它不属于这个文法的语言, 也就是不是正确的时刻. 这正是「检查语法」的做法 (第 5 题).

易错: 「推不出来」要说明原因, 不能只说「试了不行」. 标准写法就是指出卡在哪一步、缺哪条规则: 这里是小时的第一位. 用脚本核对: 文法 (II) 推出的小时, 第一位只有 0、1、2 三种.

10. 把时刻文法画成语法图
EBNF-Grammatik – Syntaxdiagramm für Uhrzeiten

Zentralübung · Folie 15 
Uhrzeit = Stunde ":" Minute
Stunde  = "00" | "01" | ... | "23"
Minute  = "00" | "01" | ... | "59"

翻译: 把文法 (I) 画成语法图.

思路: 每条规则画一张图. 并列 (先后) 画成一条直线上依次排开的方框; 选择 | 画成分叉的平行路径. 非终结符用直角方框, 终结符用圆角方框 (EIPS 02 「语法图」).

答案 (先自己做再看)
  • Uhrzeit: 一条直线, 依次经过 Stunde、「:」、Minute. Stunde 和 Minute 是非终结符, 用直角方框; 冒号是终结符, 用圆角方框.
  • Stunde、Minute: 选择 | 画成上下平行的分支, 每条分支经过一个圆角方框 (00、01、…、23 或 59), 最后汇合. 沿着任意一条从左到右走通的路径, 读出的就是一个合法的词.

语法图和 EBNF 描述的是同一个语言, 只是画成图. 文法 (II) 也可以这样画, 每个辅助非终结符各一张图, 中间的「…」就不需要了.

Aufgabe 2-1: 玩具箱的 EBNF 文法
EBNF-Grammatik für Spielzeugkisten · Präsenz

Übungsblatt 2 · Aufgabe 2-1

Im Folgenden betrachten wir eine einfache Sprache, mit der man den Inhalt von Spielzeugkisten in einem Kinderzimmer beschreiben kann. Generell wird dabei eine Spielzeugkiste durch das Wort "Kiste" angegeben und anschließend wird in runden Klammern entweder "leer" geschrieben oder es wird der Inhalt der Spielzeugkiste aufgezählt. Der Inhalt einer Spielzeugkiste besteht aus einer Reihe von Gegenständen, wobei zwischen jeweils zwei (aneinander grenzenden) Gegenständen immer angegeben werden soll, ob der erste "neben" oder "auf" dem zweiten liegt. Ein Gegenstand ist entweder ein Spielzeug oder wiederum eine Spielzeugkiste, die ihrerseits (wie oben beschrieben) angegeben wird. Spielzeuge sind "Puppe", "Auto", "Ball" oder "Teddy".

Beispiele für gültige Ausdrücke dieser Sprache sind also:

Kiste (leer)

Kiste (Puppe neben Auto auf Kiste (Teddy neben Auto) neben Ball)

Ungültig sind Konstruktionen, in denen vor oder nach einer Präposition kein Gegenstand steht, also z.B.:

Kiste (neben Auto)

Kiste (Auto neben)

翻译: 一种描述儿童房里玩具箱内容的简单语言. 一个玩具箱写成单词 "Kiste", 后面跟圆括号, 括号里要么写 "leer" (空), 要么列出箱子里的东西. 箱子里是一串物品, 每两个相邻的物品之间要写明前一个在后一个的 "neben" (旁边) 还是 "auf" (上面). 一件物品要么是玩具, 要么又是一个玩具箱 (按上面的方式写). 玩具有 Puppe (娃娃)、Auto (汽车)、Ball (球)、Teddy (泰迪熊).

不合法的是介词前面或后面没有物品的写法, 如 Kiste (neben Auto)、Kiste (Auto neben).

要抓住的结构: ① 箱子里可以再放箱子, 所以文法是递归的 (非终结符在自己的定义里再次出现); ② 物品和介词交替出现, 以物品开头、以物品结尾, 这是「A { 介词 A }」的典型形状.

a) 写出文法

Aufgabe 2-1 a)

Definieren Sie eine EBNF-Grammatik für die oben beschriebene Sprache. Das Startsymbol soll den Namen Spielzeugkiste haben.

翻译: 为上面的语言定义 EBNF 文法, 起始符叫 Spielzeugkiste.

思路: 照着描述一句一句翻: 「Kiste ( 空 或 内容 )」; 「内容 = 物品, 之后任意多次 (介词 物品)」; 「物品 = 玩具 或 玩具箱」; 「玩具 = 四个词选一个」. 用 { } 表示重复, 用 | 表示选择.

答案 (先自己做再看) 
Spielzeugkiste = "Kiste" "(" ( "leer" | Inhalt ) ")"
Inhalt         = Gegenstand { Präposition Gegenstand }
Präposition    = "neben" | "auf"
Gegenstand     = Spielzeug | Spielzeugkiste
Spielzeug      = "Puppe" | "Auto" | "Ball" | "Teddy"
  • Spielzeugkiste: "(" 和 ")" 是终结符, 要加引号. 「leer 或内容」用括号括成一组再选择, 否则 | 会把整条规则从中间分成两半 (| 的优先级最低).
  • Inhalt: 第一个物品必须有, 之后每次都是「介词 + 物品」成对出现. 这样介词前后都一定有物品, 题目里的两个反例自动被排除; 箱子里至少有一件东西, Kiste () 也被排除.
  • Gegenstand → Spielzeugkiste: 这里就是递归, 让箱子可以一层套一层.

核对: 按这个文法写了一个识别程序, 测题目里的例子: 两个合法例子都被接受; Kiste (neben Auto)、Kiste (Auto neben), 以及 Kiste ()、Kiste (leer neben Auto) 都被拒绝.

易错: 写成 Inhalt = { Gegenstand Präposition } Gegenstand 也对, 只是换了一种拆法. 写成 Inhalt = { Gegenstand | Präposition } 就错了: 它允许介词开头、两个介词相连, 也允许空内容.

文法里的终结符是一个个单词, 词与词之间的空格不写进文法: 习惯上把空格当作分隔符, 不算语言的一部分. 题目和 Zentralübung 的时刻例子都是这样处理的.

b) 长推导和短推导

Aufgabe 2-1 b)

Leiten Sie mit der oben definierten EBNF-Grammatik folgenden Ausdruck ab:

Kiste (Auto auf Kiste (leer))

Hinweis: Geben Sie sowohl die lange als auch die kurze Ableitung des Ausdrucks an. Geben Sie in jedem Schritt an, ob Sie eine Regel angewendet haben und welche Operatoren Sie angewendet haben!

翻译: 用 a) 的文法推导出 Kiste (Auto auf Kiste (leer)). 提示: 长推导和短推导都要写, 每一步都要注明用的是规则还是运算符、是哪个运算符.

思路: 长推导每一步只能做一种动作 (替换, 或执行运算符), 而且新替换出来的非终结符不能在同一步里接着替换. 这里内容有两件物品, 所以 { } 要展开一次 ({E} → E{E}), 再把剩下的 {E} 删掉. 短推导里替换和运算符可以合在一步, 而且 {E} 可以一步变成 E (EIPS 02 Folie 46 的特别规则).

答案 (先自己做再看)

长推导 (每行左边是这一步做的动作): 

Spielzeugkiste
Regel Spielzeugkiste       → "Kiste" "(" ( "leer" | Inhalt ) ")"
Op |                       → "Kiste" "(" Inhalt ")"
Regel Inhalt               → "Kiste" "(" Gegenstand { Präposition Gegenstand } ")"
Op { } (ausrollen)         → "Kiste" "(" Gegenstand Präposition Gegenstand
                               { Präposition Gegenstand } ")"
Op { } (löschen)           → "Kiste" "(" Gegenstand Präposition Gegenstand ")"
Regel Gegenstand (2×),
      Präposition          → "Kiste" "(" ( Spielzeug | Spielzeugkiste )
                               ( "neben" | "auf" ) ( Spielzeug | Spielzeugkiste ) ")"
Op | (3×)                  → "Kiste" "(" Spielzeug "auf" Spielzeugkiste ")"
Regel Spielzeug,
      Spielzeugkiste       → "Kiste" "(" ( "Puppe" | "Auto" | "Ball" | "Teddy" ) "auf"
                               "Kiste" "(" ( "leer" | Inhalt ) ")" ")"
Op | (2×)                  → "Kiste" "(" "Auto" "auf" "Kiste" "(" "leer" ")" ")"
  • 9 步, Regel 和 Op 交替出现. 第 4、5 步都是对 { } 执行运算符: 先展开一次, 再删掉新出现的 { … }. 新的 { } 是第 4 步才产生的, 不能在同一步里接着删, 所以分两步写.
  • 第 6 步同时替换了三个非终结符 (两个 Gegenstand、一个 Präposition), 这是允许的「并行替换」; 第 7 步在三处执行 |.
  • 第 8 步替换的 Spielzeugkiste 是内层的箱子, 它的规则右边又带来一个 ( "leer" | Inhalt ), 第 9 步选 "leer".

短推导: 

Spielzeugkiste
Regel Spielzeugkiste, Op |              → "Kiste" "(" Inhalt ")"
Regel Inhalt, Op { } → E                → "Kiste" "(" Gegenstand Präposition Gegenstand ")"
Regel Gegenstand (2×), Präposition,
      Op | (3×)                         → "Kiste" "(" Spielzeug "auf" Spielzeugkiste ")"
Regel Spielzeug, Spielzeugkiste,
      Op | (2×)                         → "Kiste" "(" "Auto" "auf" "Kiste" "(" "leer" ")" ")"

4 步: 每一步先替换当前已有的非终结符, 再在替换出来的选择里挑好. 第 2 步用的是短推导专用的规则 {E} → E (等于「展开一次再删掉」合成一步).

易错: 短推导里也不能「嵌套替换」. 例如第 3 步不能直接写到 "Auto": Spielzeug 是这一步才替换出来的, 要到下一步才能再替换.

c) 语法图

Aufgabe 2-1 c)

Erstellen Sie zu der oben definierten EBNF-Grammatik ein äquivalentes Syntaxdiagramm.

翻译: 为 a) 的文法画一个等价的语法图.

思路: 每条规则一张图. 并列画成一条线上依次排开; | 画成分叉; { } 画成一条向回走的环路: 走完 Gegenstand 后可以直接出去, 也可以沿下面的回路经过 Präposition 再回到 Gegenstand 前面. 非终结符用直角框, 终结符用圆角框.

答案 (先自己做再看)
  • Spielzeugkiste: Kiste → ( → 分叉 (leer 或 Inhalt) → ).
  • Inhalt: 先经过一次 Gegenstand; 回路从右往左经过 Präposition, 回到 Gegenstand 前面. 所以介词总是夹在两个物品之间.
  • Gegenstand 里的 Spielzeugkiste 指回第一张图, 这就是递归.

也可以把 Präposition 的两个选项直接画在 Inhalt 的回路上, 省掉单独的一张图, 两种画法等价.

Aufgabe 2-2: 烘焙配方的 EBNF 文法
EBNF-Grammatik für Backrezepte · Hausaufgabe

Übungsblatt 2 · Aufgabe 2-2

In einem Backrezept wollen wir beschreiben können, welche Zutaten und wie viel davon für ein Gebäck gebraucht werden. Dazu geben wir an, wie viele Teelöffel "TL" oder Esslöffel "EL" einer Zutat benötigt werden. Die Anzahl der Tee- oder Esslöffel muss eine positive ganze Zahl ungleich 0 sein. Als Zutaten können wir "Salz", "Zucker", "Mehl" und "Milch" verwenden. Ein Backrezept besteht dann aus beliebig vielen, aber mindestens einer solchen Mengenangabe.

Beispiele für gültige Backrezepte sind also:

5 EL Zucker 10 EL Mehl 20 TL Milch

1 TL Salz 1 TL Salz

Ungültig sind beispielsweise folgende Konstruktionen:

0 TL Salz

5 TL 3 EL Milch

10 EL Mehl Zucker

翻译: 烘焙配方要写明需要哪些配料、各要多少. 用茶匙 "TL" (Teelöffel) 或汤匙 "EL" (Esslöffel) 表示量, 匙数必须是不等于 0 的正整数. 配料有 Salz (盐)、Zucker (糖)、Mehl (面粉)、Milch (牛奶). 一个配方由任意多条、但至少一条这样的「用量说明」组成.

反例为什么不合法: 0 TL Salz 匙数是 0; 5 TL 3 EL Milch 的「5 TL」后面缺配料; 10 EL Mehl Zucker 的 Zucker 前面缺数量和单位. 第二个配方重复写了「1 TL Salz」, 但仍然合法: 文法只管格式, 不管有没有重复.

a) 写出文法

Aufgabe 2-2 a)

Definieren Sie eine EBNF-Grammatik für die oben beschriebene Sprache. Das Startsymbol soll den Namen Backrezept haben. Sie können folgende Regeln verwenden:

Zahl = ZifferOhne0 { Ziffer }
ZifferOhne0 = "1" | "2" | ... | "9"
Ziffer = "0" | ZifferOhne0

翻译: 为这种语言定义 EBNF 文法, 起始符叫 Backrezept. 可以直接用给出的三条规则 (正整数: 第一位 1–9, 后面任意多位 0–9).

思路: 先定义一条「用量说明」= 数字 单位 配料; 「至少一条」写成「一条, 再接任意多条」.

答案 (先自己做再看) 
Backrezept   = Mengenangabe { Mengenangabe }
Mengenangabe = Zahl Einheit Zutat
Einheit      = "TL" | "EL"
Zutat        = "Salz" | "Zucker" | "Mehl" | "Milch"
Zahl         = ZifferOhne0 { Ziffer }
ZifferOhne0  = "1" | "2" | ... | "9"
Ziffer       = "0" | ZifferOhne0
  • 「至少一条」: { Mengenangabe } 可以是零次, 所以前面单独写一条 Mengenangabe. 只写 { Mengenangabe } 会允许空配方.
  • 「不等于 0 的正整数」: 由给出的 Zahl 规则保证: 第一位是 ZifferOhne0, 所以 0、05 都推不出来; 10、20 可以 (第二位用 Ziffer 里的 "0").

核对: 把这个文法写成等价的正则表达式, 测了题目里所有例子: 两个合法配方都被接受, 三个反例都被拒绝; 另外 01 TL Salz 和空串也被拒绝, 1 TL Zucker 3 EL Mehl (b 题) 被接受.

b) 长推导和短推导

Aufgabe 2-2 b)

Leiten Sie mit der oben definierten EBNF-Grammatik folgenden Ausdruck ab:

1 TL Zucker 3 EL Mehl

Hinweis: Geben Sie sowohl die lange als auch die kurze Ableitung des Ausdrucks an. Geben Sie in jedem Schritt an, ob Sie eine Regel angewendet haben und welche Operatoren Sie angewendet haben!

翻译: 用 a) 的文法推导出 1 TL Zucker 3 EL Mehl, 长推导和短推导都要写, 每步注明规则或运算符.

思路: 两条用量说明, 所以 Backrezept 里的 { } 展开一次再删掉. 两个数都是一位数, 所以 Zahl 里的 { Ziffer } 直接删掉 (零次).

答案 (先自己做再看)

长推导: 

Backrezept
Regel Backrezept           → Mengenangabe { Mengenangabe }
Op { } (ausrollen)         → Mengenangabe Mengenangabe { Mengenangabe }
Op { } (löschen)           → Mengenangabe Mengenangabe
Regel Mengenangabe (2×)    → Zahl Einheit Zutat Zahl Einheit Zutat
Regel Zahl (2×), Einheit (2×),
      Zutat (2×)           → ZifferOhne0 { Ziffer } ( "TL" | "EL" )
                               ( "Salz" | "Zucker" | "Mehl" | "Milch" )
                               ZifferOhne0 { Ziffer } ( "TL" | "EL" )
                               ( "Salz" | "Zucker" | "Mehl" | "Milch" )
Op | (4×), Op { } (2× löschen)
                           → ZifferOhne0 "TL" "Zucker" ZifferOhne0 "EL" "Mehl"
Regel ZifferOhne0 (2×)     → ( "1" | … | "9" ) "TL" "Zucker" ( "1" | … | "9" ) "EL" "Mehl"
Op | (2×)                  → "1" "TL" "Zucker" "3" "EL" "Mehl"
  • 第 6 步在同一步里执行了两种运算符 (4 处 |、2 处删除 { Ziffer }). 长推导允许一步执行多个运算符, 只要这一步不同时做替换; 这些运算符都是这一步开始前就在式子里的.
  • Ziffer 从头到尾没有被替换: { Ziffer } 被删掉了, 里面的 Ziffer 就跟着消失了.

短推导: 

Backrezept
Regel Backrezept, Op { } → E            → Mengenangabe Mengenangabe
Regel Mengenangabe (2×)                 → Zahl Einheit Zutat Zahl Einheit Zutat
Regel Zahl (2×), Einheit (2×), Zutat (2×),
      Op | (4×), Op { } (2× löschen)    → ZifferOhne0 "TL" "Zucker" ZifferOhne0 "EL" "Mehl"
Regel ZifferOhne0 (2×), Op | (2×)       → "1" "TL" "Zucker" "3" "EL" "Mehl"

第 2 步只有替换: Mengenangabe 的规则右边没有运算符可执行. 第 3 步替换出 ZifferOhne0, 它要到第 4 步才能再替换 (不能嵌套替换).

c) 语法图

Aufgabe 2-2 c)

Erstellen Sie zu der oben definierten EBNF-Grammatik ein äquivalentes Syntaxdiagramm. Dabei brauchen Sie die Regeln für Zahl, ZifferOhne0 und Ziffer nicht beachten.

翻译: 为 a) 的文法画等价的语法图. Zahl、ZifferOhne0、Ziffer 三条规则不用画 (Zahl 当作一个现成的非终结符框).

思路: 「至少一次」画成: 先经过一次 Mengenangabe, 再从右边沿回路回到它前面 (回路上什么都不经过).

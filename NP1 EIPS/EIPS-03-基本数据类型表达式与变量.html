Lösungen

x1,2 = (−b ± √(b2 − 4 · a · c)) / (2 · a)

Folie 4

Beispiel: Schnittpunkt zweier Geraden

Gegeben: Gleichungen zweier Geraden

a1 · x + b1 = 0
a2 · x + b2 = 0

Gesucht: ihr Schnittpunkt

a1 · x + b1 = a2 · x + b2

x = (b2 − b1) / (a1 − a2)

DEMO

两条直线 y = a1x + b1 和 y = a2x + b2 的交点: 让两个 y 相等, 移项得 (a1 − a2)x = b2 − b1, 所以 x = (b2 − b1)/(a1 − a2). 再代回任一条直线就得到 y.

写成 Python: 

>>> a1, b1, a2, b2 = 2.0, 1.0, -1.0, 4.0
>>> x = (b2 - b1) / (a1 - a2)
>>> x
1.0
>>> a1 * x + b1
3.0

易错: a1 = a2 时两条线平行, 分母为 0, 程序会报 ZeroDivisionError (见 Folie 48).

幻灯片错误: 「Gleichungen zweier Geraden」写成了 a1 · x + b1 = 0 和 a2 · x + b2 = 0. 这样写的是两个关于 x 的一元一次方程, 各自只有一个解 (数轴上的一个点), 不是直线. 直线方程应为 y = a1 · x + b1 和 y = a2 · x + b2; 幻灯片下一行 a1 · x + b1 = a2 · x + b2 正是按 y 相等写的, 和上面的写法矛盾.

Grammatik für positive ganze Dezimalzahlen

Folie 9 
DecimalIntegerLiteral = DecimalNumeral
DecimalNumeral        = "0"|NonZeroDigit [ Digits ]
                        |NonZeroDigit Underscores Digits
NonZeroDigit          = "1"|"2"|…|"9"
Digits                = Digit|Digit [ DigitsAndUnderscores ] Digit
Digit                 = "0"|NonZeroDigit
DigitsAndUnderscores  = DigitOrUnderscore { DigitOrUnderscore }
DigitOrUnderscore     = Digit|"_"
Underscores           = "_"|{ "_" }

这是 Python 正整数Literal 字面量 (程序里直接写出的数) 的 EBNF 文法 (第 2 章的写法). 新东西是下划线: Python 允许在数字之间写 _ 来分组, 方便阅读, 例如 100_000 就是 100000.

  • Digits = Digit | Digit [ DigitsAndUnderscores ] Digit: 一串数字, 中间可以夹下划线, 但首尾必须是数字. 所以 1_ 不合法.
  • DecimalNumeral 的第三个选项允许在第一个数字后面直接跟下划线, 例如 1_000.
  • 和第 2 章一样, 不允许前导零: 007 不合法.

实际试一下: 

>>> 100_000
100000
>>> 1_000_000 + 1
1000001

幻灯片文法和 Python 实际规则不一致:

  1. 按这个文法, 连续多个下划线是合法的 (DigitOrUnderscore 可以重复成 __, Underscores 也可以是 __), 比如 1__0. 但 Python 规定下划线只能单个出现在两个数字之间, 1__0 报 SyntaxError: invalid decimal literal. Python 文档里的实际规则是 decinteger ::= nonzerodigit (["_"] digit)* | "0"+ (["_"] "0")* (见 Folie 10).
  2. 这个文法只允许单独一个 "0", 而 Python 允许全由 0 组成的字面量 00000 (下一张 Folie 11 的演示就输入了 00000, 结果是 0).
  3. Underscores = "_"|{ "_" } 里, { "_" } 本身就包括「一个下划线」和「零个下划线」, 所以第一个选项 "_" 是多余的; 而且零个下划线时第三个选项就和第二个选项重复了. 想表达「至少一个下划线」应写 "_" { "_" }.

定长二进制编码
Binärkodierung ganzer Zahlen mit fester Folgenlänge

Folie 12

Eine nicht-negative ganze Zahl x im Bereich [0, 2n − 1] wird codiert durch eine Bitfolge bn−1 … b0 der Länge n, so dass gilt:

x = bn−1 · 2n−1 + bn−2 · 2n−2 + … + b0 · 20 = ∑i=0n−1 bi · 2i

Beispiele für n = 3 und damit dem Bereich [0, 7]:

  • 7 wird codiert durch 111, da 1 · 22 + 1 · 21 + 1 · 20 = 4 + 2 + 1 = 7
  • 3 wird codiert durch 011, da 0 · 22 + 1 · 21 + 1 · 20 = 2 + 1 = 3

计算机里的整数通常用固定长度的位串存储. n 位能表示 0 到 2n − 1 共 2n 个非负整数. 第 i 位 bi 的权重是 2i, 从右往左数, 最右边是第 0 位.

和第 1 章的二进制一样, 区别只是长度固定: 3 写成 011 而不是 11, 不够的位在左边补 0.

Folie 13

Binärkodierung ganzer Zahlen mit fester Folgenlänge (2)

  • Darstellung positiver und negativer Zahlen:
    Verwende ein zusätzliches Bit am Anfang (1 = -, 0 = +).
  • Damit nichts verschwendet wird (doppelte 0):
    Negativer Bereich wird dargestellt durch:
    • kleinste negative Zahl (=−2n): 1 gefolgt von n 0en
    • größte negative Zahl (=−1): 1 gefolgt von n 1en

Dür n = 3 und einem Vorzeichenbit, Bereich [−8, 7]:

0 → 0000−8 → 1000
1 → 0001−7 → 1001
2 → 0010−6 → 1010
3 → 0011−5 → 1011
4 → 0100−4 → 1100
5 → 0101−3 → 1101
6 → 0110−2 → 1110
7 → 0111−1 → 1111

要表示负数, 在最前面加一个Vorzeichenbit 符号位: 0 表示正, 1 表示负. 一共 n + 1 位.

最朴素的做法是「符号位 + 绝对值」, 但那样 0000 和 1000 都表示 0 (+0 和 −0), 浪费一个编码. 所以负数换一种排法: 1000 表示最小的 −2n (n = 3 时是 −8), 然后往上数, 1111 表示 −1. 表示范围是 [−2n, 2n − 1], n = 3 时是 [−8, 7], 负数比正数多一个.

规律: 一个负数 −k 的编码, 等于把 2n+1 − k 当成无符号数写出来. 例: −3 → 16 − 3 = 13 = 1101.

原文笔误: 「Dür n = 3」应为「Für n = 3」.

Folie 14

Binärkodierung ganzer Zahlen mit fester Folgenlänge (3)

Diese Binärkodierung ganzer Zahlen nennt man Zweierkomplement

Berechnung der Zweierkomplementdarstellung einer negativen Zahl Z:

  1. Sei 0bn−1 … b0 die Binärdarstellung von |Z|
  2. Invertiere alle Bits von 0bn−1 … b0
  3. addiere 1

Beispiel: Zweierkomplementdarstellung von -56 als 32bit Zahl

1  |−56| = 56 = 0000 0000 0000 0000 0000 0000 0011 1000
2  Invertieren   1111 1111 1111 1111 1111 1111 1100 0111
3  Addiere 1     1111 1111 1111 1111 1111 1111 1100 0111
             +                                         1
                                                     111   (Überträge)
             =   1111 1111 1111 1111 1111 1111 1100 1000

Folie 13 的编码叫Zweierkomplement 二进制补码. 求负数 Z 的补码, 三步:

  1. 写出 |Z| (绝对值) 的二进制, 最前面是符号位 0;
  2. 每一位取反 (0 变 1, 1 变 0);
  3. 结果加 1.

例 −56 (32 位): 56 = 32 + 16 + 8 = 111000. 取反后末尾是 …1100 0111, 加 1 时从最右边起 1+1 进位, 连续三次进位 (图里的 111 是进位), 得到 …1100 1000. 用 Python 核对 (& 0xFFFFFFFF 取最低 32 位): 

>>> format(-56 & 0xFFFFFFFF, '032b')
'11111111111111111111111111001000'

为什么这样就对: 取反等于用 2n+1 − 1 减去原数, 再加 1 就是 2n+1 − |Z|, 正是 Folie 13 下面说的规律. 补码的好处是加法电路不用区分正负: 56 + (−56) 按普通二进制相加, 溢出的最高位丢掉, 正好是 0.

小测: 4 位补码里 −5 是多少? 5 = 0101 → 取反 1010 → 加 1 → 1011, 和 Folie 13 的表一致.

Ganze Zahlen in Python

  • Intern: Repräsentation im Zweierkomplement
  • Wissen über die Repräsentation ist manchmal, aber eher selten notwendig
  • Wichtig: keine festgelegte Größe
    • Python int kann problemlos riesige Zahlen darstellen, z.B. 2220 mit 1 Mio. Stellen
    • Anzahl der notwendigen Stellen der binären Repräsentation wird nach Bedarf automatisch angepasst

Python 的 int 没有固定位数: 数需要多少位就自动用多少位, 不会溢出. C、Java 的 int 一般固定 32 位, 超过 231 − 1 会出错或绕回负数, Python 没有这个问题.

例子 2220 = 21048576: 二进制有 1 048 577 位 (约 100 万), 十进制有 315 653 位. 「1 Mio. Stellen」指的是二进制位数. 实际运行核对: 

>>> x = 2 ** (2 ** 20)
>>> x.bit_length()
1048577

平时写程序几乎不需要关心内部表示, 只有做位运算 (&、|, 见 Folie 33) 时才用得上.

Python 的 int 内部其实是「符号 + 绝对值」存储的, 只是在做位运算 & | ^ ~ 时表现得像无限长的补码 (例如 -1 相当于无限个 1). 幻灯片说「intern Zweierkomplement」是从这个角度说的. 十进制位数超过 4300 位时, str(x) 默认会报错 (防止拒绝服务攻击的保护), 要用 sys.set_int_max_str_digits(0) 解除限制.

>>> 0.1 + 0.2

>>> 0.1 + 0.2 == 0.3

原因: 0.1 在二进制里是无限循环小数, 只能存一个近似值. 所以比较浮点数时不要用 ==, 而要看差是否足够小.

Folie 18

Normalformen von Gleitkommazahlen

Eine Gleitkommazahl r ≠ 0 wird in ihrer Normalform dargestellt durch

[ "+"|"-" ] Mantisse [ "e"|"E" ] Exponent

wobei

  • Mantisse ist eine Dezimalzahl aus dem halboffenen Intervall [1, 10[ (mit Punkt für ein Komma)
  • Exponent ist eine ganze Zahl
  • und |r| = Mantisse · 10Exponent

Falls r = 0, ist die Normalformdarstellung 0.0

Normalform 规范形式 (科学计数法): 一个非零浮点数写成「可选符号 + 尾数 + e + 指数」. Mantisse 尾数必须在 [1, 10[ 里, 也就是 1 ≤ 尾数 < 10 (德国写法 [1, 10[ 表示右端开区间, 即 [1, 10)). Exponent 指数是整数.

例: 4 000 000 = 4.0e6; 0.00042 = 4.2e-4; −0.73 = −7.3e-1. 尾数限定在 [1, 10[ 是为了让每个数只有一种写法 (否则 42e3、4.2e4、0.42e5 都表示同一个数). 0 没法这样写 (尾数会是 0), 所以单独规定为 0.0.

Beispiel zur Booleschen Logik

  1. Anna sagt: „Bettina lügt.“

Wer lügt denn nun?

...

  and ( not ( bLügt ) == ( aLügt or cLügt ) ) # Aussage 2
  and ( not ( cLügt ) == ( aLügt and bLügt ) ) # Aussage 3
...

Ausprobieren aller möglichen Belegungen zeigt, dass alleAussagen nur wahr wird bei:

aLügt = True; bLügt = False; cLügt = True

思路: 每个人说真话 ⇔ 他说的内容为真. 「Anna 不撒谎」⇔「Bettina 撒谎」, 写成 (not aLügt) == bLügt. 另外两句同理. 三个等式同时成立的情况就是答案. 一共 2³ = 8 种组合, 逐一试.

幻灯片小错: 代码把一个表达式分成三行写, 但第一行末尾括号已经闭合, Python 会在换行处结束语句, 第二行以 and 开头就是 SyntaxError. 要跨行, 必须把整个右边再包一层括号 alleAussagen = ( … \n and … \n and … ), 或在行末加反斜杠 \.

Verhalten von logischen Operatoren

  • Bei Operatoren and bzw. or wird von links nach rechts ausgewertert und das zweite Argument ignoriert (short circuit evaluation), wenn das Ergebnis nach der ersten Auswertung schon „klar“ ist.
  • Beispiele für die Konjunktion
    (0 == 1) and (100/0 > 1) ergibt False
    (100/0 > 1) and (0 == 1) ergibt Laufzeitfehler
  • Beispiele für die sequentielle und die strikte Disjunktion
    (0 == 0) or (100/0 > 1) ergibt True
    (100/0 > 1) or (0 == 0) ergibt Laufzeitfehler

Short circuit evaluation 短路求值: and 左边已经是 False → 结果一定是 False, 右边不再计算; or 左边已经是 True → 结果一定是 True, 右边不再计算.

所以 (0 == 1) and (100/0 > 1) 不会报错: 左边 False, 右边的除以 0 根本没执行. 交换顺序后先算 100/0, 立刻 ZeroDivisionError (运行时错误). 这说明 and/or 不满足交换律 (在会出错或有副作用时). 

>>> (0 == 1) and (100/0 > 1)
False
>>> (0 == 0) or (100/0 > 1)
True

实际用途: n != 0 and 100/n > 1, 先排除 n = 0 再除.

原文笔误: 「ausgewertert」应为「ausgewertet」. 另外标题写「die sequentielle und die strikte Disjunktion」, 但两个例子都是 or 的顺序 (短路) 求值, 没有给出 strikte (两边都求值) 的例子.

Präzedenz 优先级决定运算符的Bindungsstärke 结合强度: 数字越大, 运算符越「把两边的参数拉到自己身边」, 越先算. 有了优先级就可以省掉很多括号.

记忆顺序 (从先到后): 一元正负号 → 乘除 → 加减 → 按位与 & → 按位或 | → 比较 → not → and → or → 条件表达式 if else. 要点:

  • 算术 > 比较 > 逻辑: x + 1 < 10 and y = ((x + 1) < 10) and y.
  • not > and > or: a or b and not c = a or (b and (not c)).
  • & 和 | 是对整数二进制位的运算 (按位与、按位或), 优先级比比较高. 例: -4 & 4 = 4 (−4 的补码 …11100 和 4 = 00100 按位与).

幻灯片的例子补全括号前是: 3 + 5 * 4 > -2 - 2 & 4 < 1 + 2 and True or float(11.1) == 11.1. 先算各部分: 3 + 5·4 = 23; (−2 − 2) & 4 = −4 & 4 = 4; 1 + 2 = 3; float(11.1) == 11.1 是 True.

幻灯片错误 (比较运算符的括号): 幻灯片把 23 > 4 < 3 加括号成 ((23 > 4) < 3), 当成「先比较一次, 再拿 True 和 3 比」. 但 Python 的比较运算符会链接 (chaining): a > b < c 的意思是 (a > b) and (b < c), 中间的 b 只算一次. 所以正确的理解是 (23 > 4) and (4 < 3) = True and False = False; 按幻灯片的括号却是 True < 3 = 1 < 3 = True. 实际运行: 

>>> 3 + 5 * 4 > -2 - 2 & 4 < 1 + 2
False
>>> (((3 + (5 * 4)) > (((-2) - 2) & 4)) < (1 + 2))
True

整个表达式最后因为 or (float(11.1) == 11.1) 为 True, 两种理解的总结果都是 True, 碰巧没有差别. 这也是 Folie 2 里「Ist der Ausdruck 3<x<10 erlaubt?」的答案: 允许, 而且意思是 3 < x and x < 10.

幻灯片的数字 3–14 不是 Python 官方的编号, 是把 Python 文档里的优先级表 (6.17 Operator precedence) 从低到高数出来的. 中间空缺的 9、11 是幻灯片没列的 ^ (按位异或) 和 << >> (移位). 乘方 ** 比一元负号还高: -2 ** 2 = −4. 另外比较一栏在 Python 里还包括 in、not in、is、is not, 同为 7.

Folie 37

Gegeben sei ein typkorrekter Ausdruck E und ein Zustand σ für die in E vorkommenden Variablen.

Vorgehensweise zur Auswertung von E unter σ

  1. Den Ausdruck E von links nach rechts durchgehen und vollständig klammern unter Berücksichtigung der Präzedenzen.
  2. Den Ausdruck E von innen nach außen und links nach rechts durchgehen und die Operationen auswerten. Der Wert von Variablen ist dabei durch den Zustand σ bestimmt.

在状态 σ 下计算表达式 E (E 必须类型正确), 两步:

  1. 完整加括号: 从左到右, 按优先级把所有省略的括号补上.
  2. 由内向外、从左到右计算. 遇到变量就去 σ 里查它的值.
Folie 38

Auswertung von Ausdrücken (2)

Beispiel:

  • Der Zustand nach Definition x = 8; ist σ = [(x, 8, int)]
  • Auswertung von 7 < x + 3 unter σ:
    1. Vollständige Klammerung: 7 < (x + 3)
    2. 7 < (x + 3)
      =σ 7 < (8 + 3)
      =σ 7 < 11
      =σ True
  • Beachte: Jeder Auswertungsschritt wird mit =σ bezeichnet.

Ausprobieren: Sie können in Thonny mit “aktuelles Skript debuggen” und der Einzelschrittausführung (F7) die Auswertungsschritte genau nachvollziehen DEMO

Typkonvertierung (1) Implizit

Kompatibilität zwischen numerischen Datentypen

Python konvertiert automatisch Werte in ausdrucksstärkere Typen sofern es in einer Berechnung notwendig wird.

Beispiele:

  • 2 ist vom Type int

Implizite Typkonvertierung 隐式类型转换: 数值类型之间有一个「兼容」顺序 bool → int → float → complex, 箭头右边的类型表达能力更强 (每个整数也是小数, 每个小数也是复数). 运算两边类型不同时, Python 自动把「弱」的那个转成「强」的, 再计算.

>>> type(5.4 + (2 + 9j))

>>> True + 1.5

Folie 40

Auswertung von Ausdrücken (3)

Beim Auswerten von arithmetischen Ausdrücken muss die implizite Typumwandlung berücksichtigt werden!

  • Implizite Konversion als separater Schritt
    2 + 1.0 =σ 2.0 + 1.0 =σ 3.0
    3 + 5/2 =σ 3 + 2.5 =σ 3.0 + 2.5 =σ 5.5
  • Auch ok: Konversion als Teil der jeweiligen Operation
    2 + 1.0 =σ 3.0
    3 + 5/2 =σ 3 + 2.5 =σ 5.5

写求值过程时, 隐式转换可以单独写成一步 (2 → 2.0), 也可以并进运算那一步. 两种都算对. 关键是结果的类型要写对: 2 + 1.0 的结果是 3.0 (float), 不是 3.

注意 5/2 本身就得到 float 2.5 (Folie 21), 然后 3 被转成 3.0 再相加.

Typkonvertierung (2) Explizit

  • Bei expliziten Typumwandlungen konvertieren Programmierer Datentypen mit Hilfe einer eingebauten Funktion (built-in-function) typ() in einen gewünschten Datentyp.

Beispiele

  • int(2.0 + 5.0) ist vom Typ int
  • float(1.3e-7) ist vom Typ float

Beachte: Typumwandlung kann Information verlieren!

Beispiele:

  • int(5.6) hat den Wert 5
  • int(-5.6) hat den Wert -5
  • Nachkommastellen werden abgeschnitten.
  • complex(5.0) hat den Wert (5+0j)

Explizite Typumwandlung 显式类型转换: 程序员自己调用和类型同名的内置函数, 这里 typ() 代表 int()、float()、str()、complex() 等.

>>> round(5.6)
6
>>> int("42") + 1

Fehler (2)

Unterscheiden nach Zeitpunkt des Auftretens

  • Compilezeitfehler: Fehler, die vom Compiler / Interpreter vor der Ausführung erkannt werden (siehe “Assistent” in Thonny).
  • Laufzeitfehler: Fehler, die erst zur Laufzeit auftreten Z.B. Division durch 0, Datei lesen, die nicht existiert, etc.

Fehlermeldungen genau lesen und Debugger nutzen!

按「什么时候发现」分两类:

  • Compilezeitfehler 编译期错误: 程序运行前就被发现 (Python 解析代码时). 语法错误属于这一类. Thonny 的 Assistent 窗口会提示.
  • Laufzeitfehler 运行时错误: 程序运行到那一行才出现, 例如除以 0、读一个不存在的文件. Python 的类型错误也是运行时才报 (因为 Python 是动态类型).

建议: 仔细读错误信息 (最后一行写着错误类型和原因, 上面写着哪一行), 并使用调试器.

  • Ausgabe mittels Built-In Funktion print
    • Gibt den übergebenen Wert auf dem Terminal aus

Mathematische Funktionen – Modul Math in Python

  • Die Python-Standardbibliothek stellt eine Reihe von mathematischen Funktionen zur Verfügung
  • Zum Beispiel: 
    import math
y = math.sqrt(x)     // Wurzel von x
i = math.round(y)    // gerundeter Wert
u = math.max(z,10.0) // Maximum von z und 10.0
  • Siehe Python Dokumentation von Math Modul für weitere Funktionen: https://docs.python.org/3/library/math.html

标准库的 math 模块提供数学函数. 先 import math, 再用 math.函数名(…) 调用. 常用的: math.sqrt 平方根、math.floor / math.ceil 向下/向上取整、math.pi 圆周率.

幻灯片错误 (这段代码不能运行):

  1. // 在 Python 里是整除运算符, 不是注释. 写成 y = math.sqrt(x) // Wurzel von x 会被理解成「sqrt(x) 整除 Wurzel …」, 直接 SyntaxError. Python 的注释用 # (第 1 章).
  2. math 模块里没有 round 和 max. 它们是内置函数, 直接写 round(y)、max(z, 10.0). 写 math.round(y) 会报 AttributeError: module 'math' has no attribute 'round'.

正确写法 (实际运行): 

>>> import math
>>> x = 2.0
>>> z = 7.5
>>> y = math.sqrt(x)     # Wurzel von x
>>> i = round(y)         # gerundeter Wert
>>> u = max(z, 10.0)     # Maximum von z und 10.0
>>> y, i, u
(1.4142135623730951, 1, 10.0)

>>> x2 = (-b - math.sqrt(d)) / (2 * a)

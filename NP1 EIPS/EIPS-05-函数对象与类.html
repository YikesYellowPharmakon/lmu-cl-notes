Motivation

Funktionen sind

  • wieder verwendbar
  • erlauben uns den selben Code nicht immer erneut schreiben zu müssen
  • verbessert die Verständlichkeit und Qualität eines Programms
  • daher Kosten für die Entwicklung und Wartung der Software sparend

  • 程序更好懂、质量更高: 给一段代码起名字, 读的人看名字就知道它做什么; 改一处 bug 所有调用处都修好了;
  • 所以节省软件开发和维护的成本.

Funktion Quadratische Gleichung

from math import *

def quad_gleichung(a, b, c):

    x1 = (-b + sqrt(b**2 - 4*a*c))/(2*a)

    x2 = (-b - sqrt(b**2 - 4*a*c))/(2*a)

    print("1. Nullstelle: " + str(x1))
    print("2. Nullstelle: " + str(x2))

quad_gleichung(4, 12, 7)
  • ** ist der Potenzoperator
    Exponent – linker Operand potenziert mit rechts

定义函数: def 名字(参数1, 参数2, …):, 下面缩进的块是函数体. 定义本身不执行函数体, 只是把这段代码记下来.

调用函数: quad_gleichung(4, 12, 7), 这时 a、b、c 分别得到 4、12、7, 然后执行函数体. 输出: 

1. Nullstelle: -0.7928932188134524
2. Nullstelle: -2.2071067811865475

Nullstelle = 零点 (使函数值为 0 的 x). **: 左操作数的右操作数次方, b**2 = b².

Folie 10

Beispiele: Funktion int_sortierung()

def int_sortierung(x,y,z):
    if x > y:
        tmp = x
        x = y
        y = tmp

    if y > z:
        tmp = y
        y = z
        z = tmp

    if x > y:
        tmp = x
        x = y
        y = tmp
    print("Die richtige Reihenfolge ist " + str(x) +
        "," + str(y) + ","+ str(z))
int_sortierung(3,5,1)

Ausgabe: Die richtige Reihenfolge ist 1,3,5

把三个数从小到大排序. 每个 if 是一次「如果顺序反了就交换」: 交换两个变量要借一个临时变量 tmp (先把 x 存起来, 再 x = y, 再 y = 旧的 x).

  1. 比较 x, y: 保证 x ≤ y;
  2. 比较 y, z: 把最大的数换到 z (之后 z 就是最大值);
  3. 再比较 x, y: 第 2 步可能把一个小数换到了 y, 所以再排一次.

(3, 5, 1): 第 1 步不变; 第 2 步 5 > 1, 变成 (3, 1, 5); 第 3 步 3 > 1, 变成 (1, 3, 5). 用脚本把 1, 3, 5 的全部 6 种排列都试过, 都排对了.

print 的参数跨两行: 括号没闭合时 Python 自动续行.

Python 交换两个变量可以不用 tmp: x, y = y, x (元组赋值, 后面的章节会讲). 实际排序用内置的 sorted([3, 5, 1]), 得到 [1, 3, 5].

Der heutige Ölverbrauch ist 0.06007799999999999

函数定义的文法
Grammatik für Funktionsdefinition

Folie 14 
FunktionDecl = Header Block
Header       = "def" Identifier "(" [ FormalParam ] ")" ":"
FormalParam  = Identifier { "," Identifier }
Block        = { Statement }
  • Der Identifier im Header ist hier der Name der Funktion.

Beispiel:

def summe(zahl):
    zahlen = range(1,zahl+1)
    return sum(zahlen)

函数定义 = Header 头部 + 块. 头部: def、函数名、括号里可选的formale Parameter 形式参数 (用逗号分隔的标识符)、冒号.

形式参数是定义里写的名字 (这里 zahl); 调用时传进去的值叫实际参数 (下一张的 ActualParameters). summe(100) 返回 5050.

这里 Block = { Statement } 允许零条语句, 但 Python 的函数体不能为空. 什么都不想做时要写 pass. 第 4 章的定义 Block = Statement { Statement } (至少一条) 才和 Python 一致.

Folie 15

Erweiterte Grammatik für Ausdrücke mit Funktionsaufruf

Im Folgenden Wird das in Kapitel 3 eingeführte Konzept für Ausdrücke erweitert.

Expression       = Variable|Value|...
                  |UnOp Expression|"(" Expression ")"
                  |FunctionCall
Variable         = NamedVariable
NamedVariable    = Identifier
....
FunctionCall     = Identifier "(" [ ActualParameters ] ")"
ActualParameters = Expression { "," Expression }

函数调用是一种新的表达式: 函数名 + 括号里的实际参数. 实际参数本身是表达式, 所以可以写 pizza(5.5, 2 * 10, x), 甚至嵌套调用 str(pizza(…)).

原文笔误: 「Im Folgenden Wird」句中 wird 不应大写.

return 语句
Die Return-Anweisung

Folie 16

Syntax:

Statement       = ...
                 |ReturnStatement   (Return-Anweisung)
...
ReturnStatement = "return" [ Expression ]
  • Eine Return-Anweisung mit einem Ergebnisausdruck muss in jedem Ausführungspfad einer Funktion mit Ergebnis vorhanden sein.

Wirkung:

  • Die Ausführung des Funktionsrumpfs wird beendet.
  • Bei Funktionen wird der Ausdruck Expression im zuletzt erreichten Zustand ausgewertet und dessen Wert als Ergebnis bereit gestellt.

return [表达式] 是一种新语句. 效果:

  1. 立即结束函数体的执行 (后面的语句不再执行);
  2. 在当前状态下算出表达式的值, 作为调用的结果.

规则: 有返回值的函数, 每一条执行路径上都要有带表达式的 return. 例如 if 分支里 return 了, else 分支也要 return.

Python 不会强制检查这条规则: 如果某条路径没有 return 就走到了函数末尾, 函数返回特殊值 None. 不写 return 的函数 (如 quad_gleichung) 也返回 None. 这类 bug 常表现为后面出现 TypeError: … 'NoneType'. 

>>> def f(x):
...     if x > 0:
...         return 1
...
>>> print(f(-5))
None

例子: 素数测试
Beispiel: Primzahl Test

Folie 17 
# Funktionsdefinition
def ist_primzahl(n):

    prim = True

    k = 2

    while k * k <= n and prim:

        if n % k == 0:

            prim = False

        k = k +1

    return prim

# Funktionsaufruf
print(ist_primzahl(13))

判断 n 是不是Primzahl 素数: 从 k = 2 开始试除, 只要找到一个能整除 n 的 k, n 就不是素数.

  • 为什么只试到 k * k <= n: 如果 n = a·b 且 a ≤ b, 那么 a ≤ √n. 所以没有 ≤ √n 的因数, 就不会有别的因数.
  • and prim: 一旦发现因数 (prim 变 False), 循环立刻停, 不用继续试.

13: k = 2, 3 都不整除 13, k = 4 时 16 > 13 停止, 返回 True.

边界情况 (实际运行): ist_primzahl(1)、ist_primzahl(0)、ist_primzahl(-1) 都返回 True, 因为循环一次都不执行, prim 保持初值. 但 1、0 和负数都不是素数. 严格的写法要在开头加一句 if n < 2: return False.

Folie 18

Typ und Auswertung der Funktionsaufruf-Ausdruck

  • Seien n, k lokale Variablen.
  • ist_primzahl(n) hat den Typ bool
  • Sei (σ) der Zustand von oben.
  • ist_primzahl(13) =σ True
  • Bemerkung:
    • Die Berechnung der Ergebnisse von Funktionsaufruf basiert auf der Ausführung von Funktionsrümpfen (vgl. später)
    • Im allgemein ist es möglich, das der Aufruf einer Funktion nicht nur einen Ergebniswert liefert sondern auch eine Zustandsänderung bewirkt (vgl. später)

函数调用表达式也有类型和值: ist_primzahl(n) 的类型是 bool (因为返回的 prim 是 bool); 在状态 σ 下 ist_primzahl(13) 求值为 True. n、k 是函数内部的lokale Variablen 局部变量.

两点说明: 调用的值是通过执行函数体算出来的 (精确规则在后面的章节); 函数调用除了给出返回值, 还可能改变状态 (副作用, 例如 print 输出、修改对象的属性).

原文笔误: 标题「Typ und Auswertung der Funktionsaufruf-Ausdruck」应为「des Funktionsaufruf-Ausdrucks」; 「Im allgemein」应为「Im Allgemeinen」; 「möglich, das der Aufruf」应为「dass」.

Folie 19

Funktion Primzahl-Test (2)

def ist_primzahl(n):
    for i in range(2, int(sqrt(n))+1):
        if (n % i) == 0:
            return False
    return True

print(ist_primzahl(15))

Auswertung:

  • Seien n, i lokale Variablen.
  • ist_primzahl(n) hat den Typ bool
  • Sei (σ) der Zustand von oben.
  • ist_primzahl(15) =σ False

同样的算法, 用 for 和 return 写: i 从 2 试到 ⌊√n⌋; 一找到因数就 return False, 立即离开函数 (同时结束循环); 循环全部走完都没找到, 才执行最后的 return True.

15: √15 ≈ 3.87, int 截断为 3, range(2, 4) = 2, 3. i = 2 不整除; i = 3 整除 → 返回 False. 注意最后一行 return True 在 for 外面 (和 for 对齐): 如果缩进到 for 里面, 第一次试除不成功就会直接返回 True.

Folie 20

Rückgabewert Negative Eingabe?

def ist_primzahl(n):
    for i in range(2, int(sqrt(n))+1):
        if (n % i) == 0:
            return False
    return True

print(ist_primzahl(-1))

问: 输入 −1 时返回什么? 答案: 什么都不返回, 程序报错. 第一步就要算 sqrt(-1), 负数没有实数平方根, math.sqrt 抛出 ValueError. Python 3.15 的实际信息: 

ValueError: expected a nonnegative input, got -1.0

(较早的 Python 版本里这条信息是 ValueError: math domain error.) 对比 Folie 17 的 while 版本: 它不用 sqrt, 输入 −1 时返回 True. 两个「等价」的函数在边界上行为不同.

作用域
Gültigkeitsbereich

Folie 21
  • Der Gültigkeitsbereich einer lokalen Variablen ist der Block (Hier innerhalb des Funktionsrumpfs), in dem die Variable definiert wurde.
    Außerhalb dieses Blocks existiert die Variable nicht.
  • In einem untergeordneten Block bzw. innerhalb eines Funktionsrumpf sind Variable eines übergeordneten Blocks gültig und dürfen dort nicht noch einmal definiert werden.

Beispiel:

Gültigkeitsbereich 作用域: 局部变量只在定义它的块里有效, 这里是函数体. 函数外面这个变量不存在.

  • pi 定义在最外层, 作用域是整个程序, 包括函数体里面: 所以函数里可以读 pi.
  • n (参数) 和 radius 定义在函数体里, 只在函数体里有效. 在函数外写 print(radius) 会得到 NameError.

fläche_kreis(5) = 3.14 × 5² = 78.5.

幻灯片的说法对 Python 不成立: 「übergeordnete Variablen dürfen nicht noch einmal definiert werden 不允许重新定义」是 Java 等语言里局部变量的规则. 在 Python 里, 函数体中给一个和外层同名的变量赋值是允许的: 这会创建一个新的局部变量, 在函数里遮住外层的同名变量, 外层变量本身不变. 实际运行: 

>>> pi = 3.14
>>> def f():
...     pi = 3
...     return pi
...
>>> f()
3
>>> pi
3.14

所以考试按幻灯片答, 写程序时要知道 Python 的实际行为: 函数里赋值的名字都是局部的 (除非用 global 声明).

面向对象编程
Die objektorientierte Programmierung (OOP)

Folie 22

In der objektorientierten Programmierung werden Daten und Methoden, die Algorithmen implementieren, zu geschlossenen Einheiten (Objekten) zusammengefasst.

Beispiele:

  • Bankkonto
    Daten: Kontostand, Zinssatz
    Methoden: einzahlen, abheben, …
  • Punkte, Linien, Kreise in einem Zeichenprogramm
    Daten: geometrische Form
    Methoden: verschieben, rotieren …

面向对象: 把数据和操作这些数据的方法 (实现算法的函数) 打包成一个整体, 叫Objekt 对象.

例: 一个银行账户对象, 数据是余额和利率, 方法是存款、取款. 画图程序里的一个圆, 数据是位置和半径, 方法是移动、旋转. 好处: 数据和处理它的代码放在一起, 外面只通过方法使用对象.

Folie 23

Die objektorientierte Programmierung (2)

  • Ein objektorientiertes System besteht aus einer Menge von Objekten, die Methoden bei anderen Objekten (oder bei sich selbst) aufrufen.
  • Die Ausführung einer Methode führt häufig zu einer Änderung der gespeicherten Daten (Zustandsänderung).

面向对象的程序 = 一群对象, 互相 (或对自己) 调用方法. 调用方法常常会改变对象里存的数据, 也就是改变状态. 例: 调用 konto.abheben(100) 后, konto 的余额少了 100.

Folie 24

Objekte und Klassen

Objekte

  • Objekte speichern Informationen (Daten)
  • Objekte können Methoden ausführen zum Zugriff auf diese Daten und zu deren Änderung
  • Während der Ausführung einer Methode kann ein Objekt auch Methoden bei (anderen) Objekten aufrufen

Klassen

  • Klassen definieren die charakteristischen Merkmale von Objekten einer bestimmten Art:
    Attribute, Methoden (und deren Algorithmen)
  • Jede Klasse kann Objekte derselben Art erzeugen
  • Jedes Objekt gehört zu genau einer Klasse.
    Es ist Instanz dieser Klasse.

Folie 33 
from math import *

class Line:

    def __init__(self,s,e):
        self.start = s
        self.end = e

    def move(self, dx, dy):
        self.start.move(dx, dy)
        self.end.move(dx, dy)

    def length(self):
        startX = self.start.x
        endX   = self.end.x
        diffX = abs(startX - endX)
        startY = self.start.y
        endY   = self.end.y
        diffY = abs(startY - endY)
        return sqrt(diffX * diffX + diffY * diffY)

Line 的属性 start 和 end 本身是 Point 对象: 对象的属性可以是别的对象.

  • move: 线段平移 = 两个端点各自平移. 这里 Line 的方法调用了 Point 的方法 (Folie 24: 对象在执行方法时调用别的对象的方法).
  • length: 两点距离公式 √(Δx² + Δy²). self.start.x 是「当前线段的起点的 x 坐标」, 点号可以连续使用. abs 是绝对值 (这里其实可以省, 因为平方后符号无所谓).

Grammatik für Klassendeklaration (ohne Vererbung)

ClassDecl   = "class" Identifier ClassBody
ClassBody   = ConstructorDecl|MethodDecl
MethodDecl  = Header Block
Header      = "def" Identifier "(" "self" [ "," FormalParam ] ")" ":"
FormalParam = Identifier { "," Identifier }
  • ConstructorDecl ist analog zu MethodDecl, jedoch mit __init__ als Identifier im Header.
    Der Identifier muss hier gleich zum Klassennamen sein.

类声明的文法: class + 类名 + 类体; 方法声明 = 头 + 块, 头的第一个参数固定是 self. 构造方法和普通方法写法相同, 只是名字固定为 __init__.

幻灯片错误 (文法和说明与 Python 不符):

  1. 最后一句「Der Identifier muss hier gleich zum Klassennamen sein 名字必须和类名相同」是 Java 的规则 (Java 的构造方法和类同名). 在 Python 里构造方法的名字就是 __init__, 和上一句自相矛盾.
  2. ClassBody = ConstructorDecl|MethodDecl 只允许类体里有一个声明. Point 有 __init__ 和 move 两个方法, 应写成 { ConstructorDecl | MethodDecl } (加重复运算符).
  3. ClassDecl 漏了类名后面的冒号, 应为 "class" Identifier ":" ClassBody.

Folie 42

Klassentypen (2)

  • Die Werte eines Klassentyps sind Referenzen (Verweise, Zeiger, Links) auf Objekte der Klasse sowie das Element None („leere“ Referenz)
  • Dementsprechend speichern lokale Variablen eines Klassentyps Referenzen auf Objekte oder den Wert None.
  • Objekt-Referenzen können mit den Operationen == und != auf Gleichheit bzw. Ungleichheit getestet werden.
    (Achtung: Die Zeiger nicht die Inhalte werden verglichen)

Beachte: Objekte einer Klasse ≠ Werte des Klassentyps K

这一张很关键: 类类型的值不是对象本身, 而是指向对象的Referenz 引用 (也叫指针、链接), 或者 None (空引用, 不指向任何对象).

  • 变量 p 里存的是「Point 对象在哪里」, 对象本身在堆上.
  • == 和 != 比较的是引用 (是不是同一个对象), 不是内容. 两个属性完全相同的不同对象, == 也是 False (见 Folie 46).

「对象 ≠ 类类型的值」: 对象在堆上, 值是指向它的引用.

严格说, Python 的 == 默认比较是否为同一对象, 但类可以自己定义 __eq__ 方法改成比较内容 (str、list 等内置类型就是比较内容的). 专门比较「是不是同一个对象」的运算符是 is. 本课的类没有定义 __eq__, 所以 == 比较的就是引用. 

>>> p = Point(1, 2)
>>> q = Point(1, 2)
>>> p == q, p is q
(False, False)
>>> r = p
>>> r == p
True

Typ und Auswertung der neuen Ausdrücke

  • Ein Ausdruck ist (wie bisher) typkorrekt, wenn ihm ein Typ zugeordnet werden kann.
  • Die Auswertung eines Ausdrucks e erfolgt (jetzt) unter einem Zustand (σ, η), d.h. wir berechnen e =(σ,η) …
  • Der Attributzugriff mit . und der Methodenaufruf mit . haben die höchste Präzedenz 15.

Wir bestimmen nun Regeln für Typkorrektheit und Auswertung für jeden neu hinzugekommenen Ausdruck.

类型正确 = 能给它定出一个类型. 求值现在在 (σ, η) 下进行: 栈给出变量的值, 堆给出对象的属性. 点号 . 的优先级最高 (15, 比一元负号的 14 还高): -p.x 是 -(p.x); p.x + 1 是 (p.x) + 1.

Folie 51

Attributzugriff

FieldAccess = Expression "." Identifier
  • Der Ausdruck Expression muss einen Klassentyp haben und der Identifier muss ein Attribut der Klasse (oder einer Oberklasse, vgl. später) bezeichnen.
  • Das Attribut muss im aktuellen Kontext sichtbar sein.
  • FieldAccess hat dann denselben Typ wie das Attribut Identifier

Beispiel:

  • Seien p (vom Typ Point) und ln (vom Typ Line) lokale Variablen.
    • p.x hat den Typ int.
    • ln.start hat den Typ Point
    • ln.start.y hat den Typ int.

属性访问的类型规则: 点号左边必须是类类型, 右边必须是这个类 (或其父类) 的属性, 而且在当前位置可见; 整个表达式的类型 = 这个属性的类型.

例: ln.start 的类型是 Point (start 属性存的是 Point); 所以 ln.start.y 是「Point 的 y 属性」, 类型 int. 从左往右一层层推.

幻灯片前后不一致: 这里叫 FieldAccess, Folie 48 的文法里同一个东西叫 AttributeAccess. 两个名字指同一种表达式.

Folie 52

Attributzugriff: Auswertung

  • p.x, q.y, ln.end, ln.end.x, … sind Variablen, deren Werte in einem Zustand (σ, η) die Attributwerte der referenzierten Objekte sind.
  • p.x =(σ,η) 1, q.y =(σ,η) 1, ln.end.x =(σ,η) 2, …

求 p.x: 在栈里查 p → 得到指向某个 Point 的引用 → 沿箭头到堆上 → 读它的 x = 1.

ln.end.x: 栈里查 ln → 堆上的 Line → 读 end, 又是一个引用 → 沿箭头到 Point (x=2, y=1) → 读 x = 2. q 指向同一个 Point, 所以 q.y = 1.

Folie 53

Attributzugriff: Auswertung (2)

Beachte: Falls kein Objekt referenziert wird, z.B. falls p =(σ,η) None, dann erfolgt bei der Auswertung von p.x ein Laufzeitfehler

如果 p 的值是 None (不指向任何对象), 求 p.x 时运行出错. Python 的实际报错: 

AttributeError: 'NoneType' object has no attribute 'x'

这个错误很常见, 典型原因是一个函数忘了 return (返回了 None), 后面又对结果访问属性.

Folie 54

Methodenaufruf-Ausdruck

MethodCall       = Expression "." Identifier "(" [ ActualParameters ] ")"
ActualParameters = Expression { "," Expression }

Ein Methodenaufruf-Ausdruck hat also die Form e.m(a1,...,an)

  • Der Ausdruck e muss einen Klassentyp C haben und der Identifier m muss eine in der Klasse C (oder einer Oberklasse von C, vgl. später) deklarierte Methode mit bezeichnen:
    m(x1,..., xn) body
  • Die aktuellen Parameter a1,...,an sind Ausdrücke, die in Anzahl zu den formalen Parametern der Methodendeklaration passen müssen.

方法调用 e.m(a1, …, an) 的类型规则: e 必须是某个类 C 的类型; m 必须是 C (或其父类) 里声明的方法; 实际参数的个数要和方法声明的形式参数个数一致 (self 不算).

例: p1.move(-2, 1) 合法 (move 有 dx、dy 两个参数); p1.move(3) 报 TypeError, 少了一个参数.

原文笔误: 「deklarierte Methode mit bezeichnen」多了一个「mit」, 应为「deklarierte Methode bezeichnen」.

Folie 55

Methodenaufruf-Ausdruck: Beispiele und Auswertung

  • Seien p (vom Typ Point) und ln (vom Typ Line) lokale Variablen.
    • p.x hat den Typ int,
    • ln.start.y hat den Typ int
  • Sei (σ, η) der Zustand von oben.
    • ln.start.y =(σ,η) 2.
  • Bemerkungen:
    • Die Berechnung der Ergebnisse von Methodenaufrufen basiert auf der Ausführung von Methodenrümpfen (vgl. später)
    • Im allgemeinen ist es möglich, dass der Aufruf einer Methode nicht nur einen Ergebniswert liefert, sondern auch eine Zustandsänderung bewirkt (vgl. Kapitel 6)

ln.start 指向 Point (x=1, y=2), 所以 ln.start.y = 2. 方法调用的值同样是通过执行方法体算出来的 (第 6 章细讲); 方法调用还可能改变状态, 例如 move 改了对象的属性.

补一个真正的方法调用例子: 在 Folie 45 的状态下, ln.length() 的类型是 float, 值是 √((1−2)² + (2−1)²) = √2 ≈ 1.414.

幻灯片小错: 标题是「Methodenaufruf-Ausdruck: Beispiele」, 但给出的例子 p.x、ln.start.y 都是属性访问, 没有一个方法调用 (Folie 51 已经讲过这两个例子).

Folie 56

Objekterzeugungsausdruck

ClassInstanceCreation = ClassType "(" [ ActualParameters ] ")"

Ein Objekterzeugungsausdruck hat also die Form C(a1,...,an)

  • C muss eine deklarierte Klasse sein.
  • Wenn die aktuelle Parameterliste nicht leer ist, muss in der Klasse C ein Konstruktor definiert sein mit n formalen Parametern
    C(x1,..., xn) body
  • Die aktuellen Parameter a1,…,an sind Ausdrücke.
  • Der Ausdruck C(a1,...,an) hat dann den Typ C

创建对象 C(a1, …, an): C 必须是已声明的类; 有参数时, C 必须有一个接收 n 个参数的构造方法; 整个表达式的类型是 C. 例: Point(7, -4) 的类型是 Point.

在 Python 里, 「构造方法 C(x1, …, xn)」具体就是 def __init__(self, x1, …, xn).

Folie 57

Objekterzeugungsausdruck (2)

Beachte:
Wenn in der konkreten Klasse kein Konstruktor deklariert wurde, dann kann man einen „Standard-Konstruktor“ C() ohne Parameter verwenden, mit dem ein Objekt der Klasse ohne explizite Initialisierung der Attribute erzeugt wird.

类里没写 __init__ 时, 可以用不带参数的 C() 创建对象 (默认构造), 这个对象一开始没有任何属性. 反过来, 写了 __init__(self, x0, y0) 以后就不能再用 Point(): 

>>> Point()
Traceback (most recent call last):
  ...
TypeError: Point.__init__() missing 2 required positional arguments: 'x0' and 'y0'
Folie 58

Objekterzeugungsausdruck: Beispiele und Auswertung

  • Sei i (vom Typ int) eine lokale Variable.
    • p1 = Point(1,2), p1 hat den Typ Point
    • p1.x hat den Typ int
    • p3 = Point(1,i), p3 den Typ Point
    • p3.x hat den Typ int

参数可以是任意表达式, 包括变量 i. 赋值后 p1、p3 的类型都是 Point, 它们的 x 属性是 int.

Folie 59

Objekterzeugungsausdruck: Beispiele und Auswertung (2)

Mit der Zuweisung p = Point(x0,y0) wird

  1. ein neues Objekt der Klasse Point erzeugt und auf den Heap gelegt
  2. die Felder des Objekts mit den Werten von x0 und y0 initialisiert
  3. eine Referenz auf das neu erzeugte Objekt als Ergebniswert geliefert

Mit der Zuweisung p1 = Point(1,2) wird der Rumpf des benutzerdefinierten Konstruktors ausgeführt und damit den Attributen x und y des neu erzeugten Objekts die Werte 1 und 2 zugewiesen.

(Allgemeine Vorschrift zur Ausführung von Objekterzeugung folgt in Kapitel 6).

执行 p = Point(x0, y0) 时发生三件事:

  1. 在堆上创建一个新的 Point 对象;
  2. 执行 __init__, 给它的属性 (Felder 字段) 赋初值;
  3. 表达式的值是指向这个新对象的引用, 赋值把这个引用存进栈里的 p.

画状态时: 栈里多一个 p 和一个箭头, 堆上多一个框.

Folie 60

Typberechnung

from math import *

class Line:

    def __init__(self,s,e):
        self.start = s
        self.end = e

    ...

    def length(self):
        startX =
            self.start.x
        endX   = self.end.x
        diffX = startX −
            endX
        ...
        return sqrt(diffX *
            diffX + diffY *
            diffY)

问: 某个表达式的类型是什么? 按 Folie 51 的规则推: 假设 start、end 是用整数坐标创建的 Point, 那么 self.start: Point; self.start.x: int; startX − endX: int; sqrt(…): float (math.sqrt 总是返回 float); 所以 ln.length() 的类型是 float.

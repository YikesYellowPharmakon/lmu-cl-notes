Lists

  • Mutable

  • No pre-determined fixed size
  • Initialization: l = [123, 'spam', 1.23]

List Operations — What do the following operations do?

OperationResult / List after operation
myList = [3, 2, 6, 1, 8]
myList.reverse()
x = len(myList)
myList.insert(2, 5)
myList.sort(reverse=True)
myList.append(3)
x = myList.count(3)
myList.remove(3)
z = 4 in myList
myList = myList + [7, 8, 9]

翻译: 列表是任意类型对象的集合: 可变、有序、没有预先固定的长度. 下面这些操作依次执行, 每一步之后列表 (或变量) 是什么?

可变类型与不可变类型
Mutable vs. Immutable Types

Exercise Session 1 · Slide 6–8

Mutable vs. Immutable Types

  • Mutable: Objects can be changed after creation
    • Examples: lists, dictionaries, sets
    • l = [1, 2, 3]
    • l[0] = 10 → [10, 2, 3]
  • Immutable: Objects cannot be changed after creation
    • Examples: integers, strings, tuples
    • s = "hello"
    • s[0] = "H" → Error!

Immutable Objects: Strings

  • Strings are immutable: they cannot be modified after creation.
  • String operations such as replace() return a string without modifying the original object.
    • s = "hello world"
    • print(id(s)) → 12345
    • s = s.replace("world", "Python")
    • print(id(s)) → 67890
  • id() identifies an object during its lifetime.
    • Different IDs indicate different objects in memory.
    • The variable s now refers to a new object.
    • The original string was not modified.

Mutable Objects: Lists

  • Lists are mutable: they can be modified after creation.
  • Methods such as append() modify the existing object in place.
    • l = [1, 2, 3]
    • print(id(l)) → 12345
    • l.append(4)
    • print(l) → [1, 2, 3, 4]
    • print(id(l)) → 12345
  • The object’s identity remains the same.
    • The list is modified in place.
    • The variable l still refers to the same object in memory.

翻译: mutable 可变对象创建后可以修改 (列表、字典、集合); immutable 不可变对象创建后不能修改 (整数、字符串、元组), 给字符串的某一位赋值会报错. 字符串的 replace() 返回一个新字符串, 原来的对象不变; id() 在对象存活期间唯一标识它, id 不同就是不同的对象. 列表的 append() 原地修改, id 不变, 变量仍指向同一个对象.

思路: 判断一个操作是「改了对象」还是「造了新对象再让变量指过去」: 看 id 有没有变. 幻灯片上的 12345、67890 只是示意的数字, 实际的 id 是很长的整数, 每次运行都不同.

答案 (先自己做再看)

实际运行 (只比较 id 是否相同, 不打印具体数字):

>>> s = "hello"
>>> s[0] = "H"
TypeError: 'str' object does not support item assignment
>>> s = "hello world"
>>> i1 = id(s)
>>> s = s.replace("world", "Python")
>>> i1 == id(s)
False
>>> l = [1, 2, 3]
>>> i = id(l)
>>> l.append(4)
>>> l, i == id(l)
([1, 2, 3, 4], True)

想把 "hello" 改成 "Hello", 只能造新字符串: s = "H" + s[1:].

字符串格式化
String Formatting

Exercise Session 1 · Slide 9–10
  • String formatting allows us to insert variables into strings.
  • Common approaches in Python:
    • format() method
    • % operator (older style)
    • f-strings (Python 3.6+, recommended)
  • Example:
who = "knights"
what = "Ni!"

print("{} say '{}'".format(who, what))
print(f"{who} say '{what}'")
# Both output: knights say 'Ni!'
  • F-strings can also format values and expressions.
  • Example:
import math

print(f"Pi is approximately {math.pi:.3f}")
# Output: Pi is approximately 3.142
  • :.3f means:
    • f: floating-point number
    • .3: 3 digits after the decimal point

See https://docs.python.org/3/tutorial/inputoutput.html

翻译: 字符串格式化把变量插进字符串. 常见三种写法: format() 方法、% 运算符 (旧写法)、f-string (Python 3.6 起, 推荐). f-string 还能在花括号里写格式说明: :.3f 表示按浮点数输出、小数点后 3 位.

思路: 作业里的 happy_birthday 就要用到它.

答案 (先自己做再看)

三种写法实际运行, 输出相同:

>>> print("{} say '{}'".format(who, what))
knights say 'Ni!'
>>> print(f"{who} say '{what}'")
knights say 'Ni!'
>>> print("%s say '%s'" % (who, what))
knights say 'Ni!'
>>> print(f"Pi is approximately {math.pi:.3f}")
Pi is approximately 3.142

.3f 是四舍五入 (π = 3.14159…, 第四位是 5, 进位成 3.142), 不是截断.

嵌套列表的浅拷贝与深拷贝
Shallow Copy / Deep Copy of a list of lists

Exercise Session 1 · Slide 11–13

Shallow Copy of a list of lists (verschachtelte Liste)

>>> x = ['a', 'b', ['c', 'd'], 'e']
>>> y = x[:]
>>> y
['a', 'b', ['c', 'd'], 'e']
>>> x[2][0] = 'z'
>>> x
['a', 'b', ['z', 'd'], 'e']
>>> y
['a', 'b', ['z', 'd'], 'e']
>>> x[0] = 'q'
# a new string object 'q' is
# created, 'a' is not changed
>>> x
['q', 'b', ['z', 'd'], 'e']
>>> y
['a', 'b', ['z', 'd'], 'e']
Exercise Session 1 · Slide 14

Deep Copy (“tiefe Kopie”) of a list of lists

A deep copy creates a new list object and adds references to new copies of the objects Attention: can be expensive to run! (http://docs.python.org/3.2/library/copy.html)

>>> x = ['a', 'b',
['c', 'd'], 'e']
>>> from copy import deepcopy
>>> y = deepcopy(x)
>>> y
['a', 'b', ['c', 'd'], 'e']
>>> x[0] = 'q'
>>> y[2][1] = 'z'
>>> x
['q', 'b', ['c', 'd'], 'e']
>>> y
['a', 'b', ['c', 'z'], 'e']

翻译: shallow copy 浅拷贝 x[:] 只复制最外层列表: 新列表的每个位置存的是和原列表相同的引用. 所以改内层列表的元素 (x[2][0] = 'z'), x 和 y 都受影响; 但给 x[0] 赋新值只是让 x 的第 0 格指向新对象 'q', y 不变. deep copy 深拷贝 (copy.deepcopy) 连内层对象也一起复制, 两边完全独立; 代价是可能很慢.

思路: 每一步都问: 这一行是「改了某个对象的内容」, 还是「让某一格指向另一个对象」? 前者影响所有指向这个对象的变量, 后者只影响这一格. 对照图里的箭头看.

答案 (先自己做再看)

实际运行:

>>> x = ['a', 'b', ['c', 'd'], 'e']; y = x[:]
>>> x[2][0] = 'z'; x, y
(['a', 'b', ['z', 'd'], 'e'], ['a', 'b', ['z', 'd'], 'e'])
>>> x[0] = 'q'; x, y
(['q', 'b', ['z', 'd'], 'e'], ['a', 'b', ['z', 'd'], 'e'])
>>> x = ['a', 'b', ['c', 'd'], 'e']; y = deepcopy(x)
>>> x[0] = 'q'; y[2][1] = 'z'; x, y
(['q', 'b', ['c', 'd'], 'e'], ['a', 'b', ['c', 'z'], 'e'])

与幻灯片一致. 浅拷贝的其他写法: list(x)、x.copy()、copy.copy(x); 都只复制一层.

易错: 「浅拷贝后改 x[0], y 也变」是错的: 字符串 'a' 本身没被改, 只是 x 的第 0 格换了指向. 只有改可变的内层对象时两边才会一起变.

幻灯片小错: Slide 14 的文档链接指向 Python 3.2 的旧文档 (docs.python.org/3.2/library/copy.html); 当前版本的地址是 docs.python.org/3/library/copy.html, 内容相同. 另外第一句「adds references to new copies of the objects」后面缺句号, 直接接 Attention.

比较值与比较引用
Comparing Values · Comparing references

Exercise Session 1 · Slide 15–16 
>>> x = [1, [2, 3], 4]
>>> y = x[:] # make a shallow copy of x
>>> # Do x and y contain the same values?
>>> x == y
True

var1 == var2 check if the objects they refer to are the same (and thereby the same values)

>>> x = [1, [2, 3], 4]
>>> y = x[:] # make a shallow copy of x
>>> # Do x and y point to the same memory location?
>>> # = Are x and y the same list object?
>>> x is y
False
>>> # Do x and y contain the same sublist?
>>> x[1] is y[1]
True

var1 is var2 tells us if the two variables refer to the same address in memory

翻译: == 问「x 和 y 的值是否相同」; is 问「x 和 y 是否指向内存中的同一个对象」. 浅拷贝后 x 和 y 值相同、不是同一个列表, 但它们的下标 1 指向同一个内层列表.

思路: 用上一题的图: 两个外层列表是两个框, 所以 x is y 为假; 两个框的第 1 格箭头指向同一个内层列表, 所以 x[1] is y[1] 为真.

答案 (先自己做再看) 
>>> x = [1, [2, 3], 4]; y = x[:]
>>> x == y, x is y, x[1] is y[1]
(True, False, True)
>>> a = [1, 2]; b = [1, 2]
>>> a == b, a is b
(True, False)

第二个例子说明 == 只比较值: a 和 b 是两个独立创建的列表, 不是同一个对象, 但 a == b 仍为 True.

幻灯片错误: Slide 15 写「var1 == var2 check if the objects they refer to are the same (and thereby the same values)」, 这把 == 说成了检查「是否同一个对象」, 那是 is 的含义. == 只比较值: 两个不同的对象只要值相等就返回 True (正如幻灯片自己的例子, x 和 y 不是同一个对象, x == y 却是 True). 反过来才成立: 同一个对象 (is 为真) 的值一定相等.

翻译: 把每个函数里的 pass 换成代码, 使函数按说明和 doctest 工作. ① 打印一句欢迎语 (字符串里本身带双引号); ② 计算 x mod y (返回, 不打印); ③ 判断 x 是否为奇数, 要用到 modulo.

思路: ① 外层用单引号, 里面的双引号就不用转义. ② % 是取余运算符. ③ 奇数 = 除以 2 余 1. 注意负数 −3 的情况.

答案 (先自己做再看) 
def hello_semester():
    print('Welcome to "Symbolische Programmierung" WS 26/27')

def modulo(x, y):
    return x % y

def odd_number(x):
    return modulo(x, 2) == 1
>>> hello_semester()
Welcome to "Symbolische Programmierung" WS 26/27
>>> modulo(5, 3), modulo(100, 24), modulo(70, 7)
(2, 4, 0)
>>> odd_number(15), odd_number(6), odd_number(-3)
(True, False, True)
>>> -3 % 2
1

讲解: Python 的 % 结果符号跟除数一致, 所以 -3 % 2 是 1, odd_number(-3) 正确返回 True. (在 C、Java 里 −3 % 2 是 −1, 那里写 == 1 会出错; Python 里没有这个问题.)

易错: modulo 要 return, 不能 print: doctest 看起来都显示 2, 但 odd_number 调用 modulo 时拿到的会是 None, 比较 None == 1 永远为 False.

原题前后不一致: 作业 PDF 里要打印的字符串是「"Welcome to "Symbolische Programmierung" WS 26/27 "」, 结尾 27 后面多一个空格; 而 doctest 和 unittest 期望的输出结尾没有空格. 照 PDF 加空格, doctest 和 unittest 都会失败. 以 doctest 为准.

def second_element(list_a):
    return list_a[1]

def concatenate_lists(list_a, list_b):
    return list_a + list_b

def swap_half(list_a):
    half = len(list_a) // 2
    return concatenate_lists(list_a[half:], list_a[:half])

def replace_elements(list_a, replacement_indices, new_value):
    for i in replacement_indices:
        list_a[i] = new_value
    return list_a

def long_strings(string_list, max_length):
    return [len(s) > max_length for s in string_list]
>>> swap_half(listOne)
['Italy', 'Poland', 'France', 'Germany', 'Spain']
>>> replace_elements([1,2,3,4,5,6,7,8], [0,4,3], 0)
[0, 2, 3, 0, 0, 6, 7, 8]
>>> long_strings(listOne, 5)
[True, False, False, True, True]

讲解:

import re

def no_numbers(string):
    return re.search(r"[0-9]", string) is None

def contains_substring(substring, string):
    return substring.lower() in string.lower()
>>> no_numbers("Guten Tag!"), no_numbers("jm584dmdk30")

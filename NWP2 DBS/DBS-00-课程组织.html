实用工具
Auswahl nützlicher Werkzeuge

Folie 10
  • DuckDB (eingebettetes Datenbanksystem, installierbar z. B. über pip)
  • SQL-Fiddle (Webdienst zum Ausführen von Abfragen auf verschiedenen Datenbanksystemen)
  • DB-Fiddle (Webdienst zum Ausführen von Abfragen auf verschiedenen Datenbanksystemen, deutlich mehr Optionen)
  • Relax (Editor und Prozessor für Relationale Algebra)
  • ChatGPT (Datensatzgenerierung)
工具是什么什么时候用
DuckDB嵌入式数据库系统: 不需要单独安装服务器, 作为一个库在程序里运行; pip install duckdb 即可在本地练 SQL; 可以直接对 CSV 文件写查询 (第 1 章笔记里用过)
SQL-Fiddle网页服务, 在不同的数据库系统上运行查询不想安装时在浏览器里试 SQL
DB-Fiddle同上, 选项多得多 (可选 PostgreSQL、MySQL、SQLite 的不同版本)比较不同系统的行为
Relax关系代数的编辑器和求值器第 3 章关系代数的练习
ChatGPT生成测试数据需要一批示例数据来测试查询时

用 DuckDB 练习最方便: 在终端运行 duckdb (命令行版) 或在 Python 里 import duckdb; duckdb.sql("SELECT 42"). 用 AI 生成测试数据时要检查数据是否符合约束 (主键唯一、外键存在), 否则查询结果会误导你.

(Abbildungen der Buchumschläge.)

五本教材: Kemper/Eickler 是德国大学最常用的德语数据库教材 (第 1 章幻灯片里 Assistent、PersNr 这类例子就来自它的大学数据库示例); Elmasri/Navathe 有德语版和英语版, 英语原版讲得最全面; Heuer/Saake/Sattler 是另一本德语经典; Ramakrishnan/Gehrke (俗称「牛书」) 是英语世界常用教材, 后半部分的存储和查询处理讲得很深.

建议: 主读 Kemper/Eickler (德语术语和考试表述一致), 遇到不懂的地方查 Elmasri/Navathe 英语版.

原文小错: 英语版 Elmasri/Navathe《Fundamentals of Database Systems》第 7 版的出版社写成「Pearson Studium」; Pearson Studium 是 Pearson 的德语教材品牌, 英语原版应为 Pearson. Ramakrishnan/Gehrke 第 3 版没有写出版年份 (2003).

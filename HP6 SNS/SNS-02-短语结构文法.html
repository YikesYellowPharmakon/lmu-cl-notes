词汇范畴
Lexikalische Kategorien

Folie 2–4

Lexikalische Kategorien = Wortarten / Parts-of-Speech

  • Wort = atomare syntaktische Einheit
    → terminale Konstituenten im Syntaxbaum
  • Wortart = Klasse von Wörtern mit gemeinsamen Eigenschaften
    → sog. ’präterminale’ Konstituenten im Syntaxbaum

Lexikalische Regeln im Syntaxbaum

  • Formalisierung der Zuordnung von Wörtern zu ihren Wortarten
  • z.B. ADJ → gut
    → Zuordnung des Wortes gut zu der POS-Kategorie Adjektiv

Klassifikation nach verschiedenen Kriterien

  • morphologische Klassifizierung
  • syntaktische Klassifizierung
  • semantische Klassifizierung

lexikalische Kategorie 词汇范畴 = 词类 / Parts of Speech. 词 = 原子性的句法单位 → 句法树里的终端成分 (叶子). 词类 = 具有共同性质的词的类别 → 句法树里所谓的präterminal 前终端成分 (叶子正上方那一层). 句法树里的词汇规则: 把词归入它的词类的形式化写法, 如 ADJ → gut (把 gut 归入词类「形容词」). 分类依据不同标准: 形态的、句法的、语义的.

例子: 树 (NP (DET der) (N Hund)): der、Hund 是终端节点; DET、N 是前终端节点; NP 是非终端节点 (见 Folie 20).

Morphologische Kriterien

Folie 5

Differenzierung über die Art ihrer grammatischen Merkmale

  • Flexionsparadigmen: { Tür | Welt } -en vs. { geh | steh } -e/st/t (*Welt-st)
    → Genus+Numerus vs. Person+Numerus

flektierbar : deklinierbar : komparierbar : unflektierbar

  • Derivationsmorphologie: { new | beautiful } -ly
    → Adjektive bilden im Englischen in Kombination mit -ly Adverbien

按词具有的语法特征的种类来区分. 屈折变化表 (Flexionsparadigma): Tür、Welt 加 -en (Türen, Welten), geh、steh 加 -e/-st/-t (gehe, gehst, geht); *Weltst 不存在 → 名词按性和数变化, 动词按人称和数变化. 分类: 可屈折的 : 可变格的 : 可比较的 : 不可屈折的. 派生形态: new、beautiful 加 -ly → 英语里形容词加 -ly 构成副词 (newly, beautifully).

形态标准问的是「这个词能怎么变」: 能变格 (名词、形容词、冠词)、能变位 (动词)、能比较 (形容词: schön, schöner, am schönsten)、完全不变 (介词、连词、副词). 能接相同词尾的词属于同一类.

句法标准
Syntaktische Kriterien

Folie 6

Differenzierung über Distribution

  • Auftreten in gleichen Kontexten (distributionsäquivalent)
  • z. B.: Adjektiv zwischen DET und NOUN oder nach Form von sein

Differenzierung über morphosyntaktisches Verhalten

  • z.B. Präposition vs. Konjunktion (beide: unflektierbar)
    • Präposition: regiert Kasus in Umgebung
      → wegen des Hundes ... (PP) vs. weil der Hund ... (CONJ)

Differenzierung über syntaktische Funktion

  • Prädikat : Subjekt : Objekt : Adverbial : Attribut

按Distribution 分布区分: 出现在相同语境中 (分布等价); 例如形容词出现在冠词和名词之间 (der rote Ball), 或 sein 的某个形式之后 (der Ball ist rot). 按形态句法行为区分: 例如介词和连词都不可屈折, 但介词会支配周围成分的格 → wegen des Hundes (介词 wegen 要求二格, 构成 PP) vs. weil der Hund … (连词 weil 引出从句, 后面是普通主格). 按句法功能区分: 谓语 : 主语 : 宾语 : 状语 : 定语.

wegen 和 weil 意思几乎一样 (「因为」), 形态上也都不变, 只有看它们对后面成分的影响才能区分: 介词支配格, 连词引出完整的句子. 这正是句法标准的价值.

Semantische Kriterien

Folie 7

Differenzierung Wörter über ihre Bedeutung

  • Verb: bezeichnet Zustände, Vorgänge, Tätigkeiten, Handlungen
  • Nomen: bezeichnet Lebewesen, Sachen (Dinge), Begriffe (Abstrakta), Individuen
  • Adverb: bezeichnet nähere Umstände von Sachverhalten
  • Adjektiv: bezeichnet Eigenschaften und Merkmale von Sachen

weitere semantische Unterscheidungen

  • Auto- vs. Synsemantika
    • Inhaltswörter: selbständige lexikalische Bedeutung; satzgliedfähig (Funktion als Phrasenkopf)
    • Funktionswörter: grammatische Bedeutung (abhängig von Bezugswort); nicht satzgliedfähig
  • offene vs. geschlossene Klassen
    • endliche/abgeschlossene vs. potentiell unendliche Menge

按意义区分: 动词表示状态、过程、活动、行为; 名词表示生物、事物、概念 (抽象事物)、个体; 副词表示事态的具体情况; 形容词表示事物的性质和特征. 其他语义区分: Autosemantika 实词 / Synsemantika 虚词 —— 实词 (Inhaltswort 内容词) 有独立的词汇意义, 能做句子成分 (能当短语的中心语); 功能词 (Funktionswort 功能词) 只有语法意义 (依赖于它所关联的词), 不能单独做句子成分. 开放类 vs. 封闭类: 有限的/封闭的集合 vs. 潜在无限的集合.

例子: 名词、动词、形容词是开放类 (随时有新词: googeln, Smartphone); 冠词、介词、连词是封闭类 (德语的冠词就那几个). 开放类大致等于实词, 封闭类大致等于功能词.

易错: 卡片里「endliche/abgeschlossene vs. potentiell unendliche Menge」的顺序与「offene vs. geschlossene」相反: 开放类 = 潜在无限, 封闭类 = 有限.

Folie 9

keine direkte Entsprechung Semantik - syntaktische Funktion

  • z. B.: prototypisches Nomen kann syntaktisch Teil des Prädikats sein, also eine andere syntaktische Funktion erfüllen (Prädikativum):
    Er ist Lehrer.
  • z. B.: Wörter mit nicht-nominaler Semantik können eine prototypische nominale Strukturposition einnehmen (z.B. als Subjekt fungieren):
    Blau ist eine Farbe.
  • Adjektive können attributiv, adverbial oder prädikativ gebraucht werden

Wortarten sind außerdem sprachabhängig

  • es gibt Sprachen, die keine Eigenschaftswortklasse haben (Dyirbal, Lakhota; s. VanValin 2000, 12)
    • die typische syntaktische Funktion, die in indogermanischen Sprachen Adjektive übernehmen (Attributfunktion), wird hier von Nomen (Dyirbal) bzw. Verben (Lakhota) übernommen

语义和句法功能之间没有直接对应. 例: 典型的名词可以在句法上充当谓语的一部分, 承担另一种句法功能 (Prädikativum 表语): Er ist Lehrer (他是老师). 例: 语义上不是名词性的词, 可以占据典型的名词位置 (如做主语): Blau ist eine Farbe (蓝色是一种颜色). 形容词可以作定语、状语或表语用. 此外词类依语言而异: 有些语言没有形容词类 (Dyirbal、Lakhota; 见 Van Valin 2000, 12) —— 在印欧语里由形容词承担的典型句法功能 (定语), 在这些语言里由名词 (Dyirbal) 或动词 (Lakhota) 承担.

形容词三种用法: das schnelle Auto (定语) / das Auto fährt schnell (状语) / das Auto ist schnell (表语). 同一个词, 三种功能.

Folie 10

Strukturalismus

  • Definition Wortklassen über (morpho)syntaktische Eigenschaften
  • Bestimmung Klassenmitglieder über syntaktisches Verhalten
  • = Distributionalismus

Syntaktisches Wortartkriterium

  • Kriterium: Auftreten in gleichen Kontexten (distributionsäquivalent)
    • Distribution = Menge der Kontexte
  • Beispiel NLTK:
    text.similar('bought') > made done put said found

Generative Grammatik

  • ebenfalls syntaktisches Wortartkriterium
  • Kriterium: Besetzung gleicher Strukturpositionen

结构主义: 通过 (形态) 句法性质定义词类; 通过句法行为确定类的成员; 这就是Distributionalismus 分布主义. 句法词类标准: 出现在相同语境中 (分布等价); 分布 = 语境的集合. NLTK 例子: text.similar('bought') 找出与 bought 出现在相似语境里的词: made done put said found. 生成语法同样用句法标准: 占据相同的结构位置.

NLTK 例子说明: similar 统计「左邻词 + 右邻词」组成的语境, 找出共享语境最多的词. 结果全是过去式/过去分词动词, 说明不看意义、只看分布, 也能归纳出词类.

text.similar 是 NLTK 里 nltk.Text 对象的方法 (NLTK 书第 1 章用 text1.similar('monstrous') 演示). 它直接打印结果, 不返回列表; 幻灯片里的「>」只是表示输出. 具体列出哪些词取决于所用的文本, 这里没有说明文本, 无法重现.

1.2 传统语法作为词类语法
1.2. Traditionelle Grammatik als Wortartengrammatik

Folie 11–12

traditionelle Grammatik

  • histor.: Acht-Wortarten-Lehre (Dionysios Thrax, 2. Jhd. v. Chr.):
    • Nomen, Verb, Partizip, Adverb, Pronomen, Artikel, Präposition, Konjunktion
  • reine Wortarten-Syntax (nur lexikalische Kategorien)
  • keine Phrasenebene (keine (höheren) syntaktischen Kategorien)

Problem

  • ohne Phrasenebene: sehr viele Satzschemata: S → { Satzschema 1 | … }

Lösung: Phrasenstrukturgrammatik

  • wenige Phrasenstruktur-Regeln können große Anzahl an Satzschemata generieren
  • durch rekursive Regeln: unendlich viele Satzschemata generierbar

传统语法: 历史上的八大词类学说 (狄奥尼修斯·特拉克斯, 公元前 2 世纪): 名词、动词、分词、副词、代词、冠词、介词、连词; 纯粹的词类句法 (只有词汇范畴); 没有短语层 (没有更高的句法范畴). 问题: 没有短语层就需要非常多的句型: S → {句型 1 | …}. 解决办法: 短语结构文法 —— 少数几条短语结构规则就能生成大量句型; 有了递归规则, 甚至能生成无限多的句型.

6 条短语结构规则 → 14 个词类句型.

为什么是 14: NP 有 2 种展开 (DET N 或 N). 主语 NP: 2 种; VP: V (1 种) + V NP (2 种) + V NP NP (2 × 2 = 4 种) = 7 种. 合计 2 × 7 = 14. 我用 NLTK 的 generate 枚举了这 6 条规则能生成的全部词类串, 恰好是幻灯片上的 14 个, 一个不多一个不少.

传统语法要把 14 个句型一个个列出来, 短语结构文法只要 6 条规则. 规则越多、可选成分越多, 差距越大 (乘法关系). 加一条递归规则 (如 NP → NP PP), 句型就变成无限多.

Motivation für Klassifizierung in Syntaxanalyse

Folie 14

Wort- und Phrasenklassen-basierte Schemata

  • ökonomische und adäquate Modellierung hierarchische Struktur:
    → ökonomisch: viele Satzschemata durch wenige Regeln generierbar
    → beschreibungsadäquat: Phrasen empirisch feststellbar

Lexikalische Regeln: N → 'Hund' | 'Katze'

  • Zuordnung lexikalischer Einheiten (Wörter) zu ihren lexikalischen Kategorien (Wortarten, Part-of-Speech-Kategorien)
    → POS = Klassen sich syntaktisch gleichverhaltender Wörter
    → Wörter austauschbar im selben Kontext

Syntaktische Regeln: NP → DET N | N

  • Regeln der Kombination von lexikalischen Kategorien (Wortarten) zu komplexeren syntaktischen Einheiten (Konstituenten, Phrasen, Sätze)
    → Wortgruppen austauschbar im selben Kontext

基于词类和短语类的句型能经济而恰当地为层级结构建模: 经济 —— 少数规则生成很多句型; 描写上恰当 —— 短语可以通过经验 (测试) 确定. 词汇规则 (N → 'Hund' | 'Katze'): 把词汇单位 (词) 归入词汇范畴 (词类) → 词类 = 句法行为相同的词的类 → 这些词在同一语境中可以互换. 句法规则 (NP → DET N | N): 把词汇范畴组合成更复杂的句法单位 (成分、短语、句子) 的规则 → 这些词组在同一语境中可以互换.

两种规则对应两种「可互换」: 词汇规则说哪些词可以互换, 句法规则说哪些词组可以互换. 这正是 SNS 01 的替换测试的形式化.

Eigenschaften der Konstituentenstruktur

Folie 15–17

Konstituentenanalyse

auch IC-Analyse (Analyse der immediate constituents)

  1. Zerlegung syntaktischer Einheit in ihre Teile (Konstituenten)
  2. Bildung von Konstituentenklassen (lexikalische und syntaktische Kategorien)
  • Ermittlung über Konstituententests
  • Ergebnis ist eine hierarchisch gegliederte Struktur

unmittelbare Konstituenten (immediate constituents)

unmittelbare Konstituenten sind die maximalen Konstituenten einer Einheit (aus denen sie unmittelbar zusammengesetzt ist)

Konstituentenanalyse 成分分析, 也叫 IC 分析 (直接成分分析): ① 把句法单位拆成它的部分 (成分); ② 建立成分类 (词汇范畴和句法范畴). 通过成分测试确定; 结果是一个层级分明的结构. 直接成分: 一个单位的最大成分 (它直接由这些成分组成).

「最大」的意思: Der Junge verkauft die Äpfel 的成分有 der、Junge、der Junge、verkauft、die Äpfel 等等, 但它的直接成分只有两个最大的: [der Junge] 和 [verkauft die Äpfel]. 其他的都在这两个里面.

Konstituenz-Relation

Folie 18

Konstituenz
Teil-Ganzes-Beziehung zwischen sprachlichen Einheiten (Konstituenten)

unmittelbare Dominanz
Beziehung der unmittelbaren Dominanz zwischen Einheit und ihren unmittelbaren Konstituenten

Dominanz
Beziehung der Dominanz zwischen Einheit X und der unmittelbare Konstituente Y; sowie zwischen X und Z, wenn Y Z dominiert (transitive Relation)

成分关系: 语言单位 (成分) 之间的部分-整体关系. unmittelbare Dominanz 直接支配: 一个单位与它的直接成分之间的关系. Dominanz 支配: 单位 X 与它的直接成分 Y 之间的关系; 以及当 Y 支配 Z 时, X 与 Z 之间的关系 (传递关系).

形式化: 直接支配 = 树里的母-子边. 支配 = 直接支配的传递闭包: 从 X 沿着边一直往下走能到达的所有节点, 都被 X 支配. 例: S 直接支配 NP 和 VP; S 支配树里的每一个节点.

原文笔误: 「zwischen Einheit X und der unmittelbare Konstituente Y」: zwischen 后接三格, 应为 der unmittelbaren Konstituente.

2.2. Eigenschaften von Phrasen

成分的分类
Klassifizierung von Konstituenten

Folie 21–22

Phrasen als spezielle Konstituentenklassen

  • im gleichen Kontext austauschbare Konstituenten bilden Konstituentenklassen
  • Phrasen sind spezifische Klassen von Konstituenten, die im Satz eine ähnliche syntaktische Funktion erfüllen
  • die syntaktische Funktion wird primär vom sog. Phrasenkopf bestimmt, dem Kern der Phrase

Phrase

  • Phrase = Konstituente, in der ein (Inhalts-)Wort als Phrasenkopf um Wörter oder Phrasen erweitert ist
    → in Terminologie der Generativen Grammatik: maximale Projektion
  • Eine Phrase ist also eine Konstituente, die eine sinnvolle Einheit bilden, wobei der Phrasenkopf das zentrale Wort ist, das die grammatische Rolle und Bedeutung der gesamten Phrase bestimmt

短语是特殊的成分类: 在同一语境中可互换的成分构成成分类; 短语是在句中承担相似句法功能的特定成分类; 句法功能主要由所谓的Phrasenkopf 短语中心语 (短语的核心) 决定. Phrase 短语 = 一个 (实) 词作为中心语、再加上其他词或短语扩展而成的成分 → 生成语法的术语叫maximale Projektion 最大投射. 所以短语是构成一个有意义单位的成分, 其中心语是决定整个短语语法角色和意义的核心词.

例子: das kleine Kind (那个小孩) 的中心语是 Kind: 整体是名词性的, 能做主语或宾语, 意义也是「某个孩子」. 「最大投射」: Kind 可以一层层扩展 (Kind → kleine Kind → das kleine Kind), 扩展到不能再扩展的那一层就是 NP.

原文笔误: 「eine Konstituente, die eine sinnvolle Einheit bilden」: 关系从句的主语是单数 die (= eine Konstituente), 动词应为 bildet.

    • Verbalphrase (VP): VP → V NP

    • Präpositionalphrase (PP): PP → P NP

Beispiel

  • In der Nominalphrase das rote Auto ist rote Auto eine Ko-Konstituente

层级的、递归的结构构造: 短语最少只由它的中心语构成 (短语核心: VP → V); 短语可以包含其他短语作为下级成分, 例如 VP → V NP、NP → DET N PP、PP → P NP; 短语可以递归构造 (比较上面 NP 和 PP 的规则: PP 里有 NP, NP 里又有 PP, 形成 (间接的) 递归 PP 嵌入), 例如「邮递员和他的朋友 (来自清洁人员 (属于大楼 (在十字路口 (在北端 (属于小镇))))) 一起吃午饭」. 例: 在名词短语 das rote Auto 中, rote Auto 是一个并列成分 (Ko-Konstituente, 与 das 并列), 但 rote Auto 本身不是独立的短语 (不完整), 比如没有冠词就不能在句中做主语.

间接递归: NP → DET N PP, PP → P NP: NP 不直接调用自己, 而是经过 PP 绕一圈再回到 NP. 所以可以无限嵌套: lunch with his friend from the staff of the building …

rote Auto 的例子: 它是成分 (das 和 rote Auto 是 NP 的两个直接成分), 但不是短语, 因为不能独立使用: *Rote Auto fährt schnell. 短语 = 「完整的」最大投射.

中心语原则
Kopfprinzip

Folie 25

Phrasenkopf

  • alle Wörter und Phrasen in der Phrase sind zum Kopf dependent
  • Kopf vererbt morphosyntaktische Merkmale an Phrase (Kasus usw.)
  • Kopf steuert syntaktisches Verhalten der Konstituente im Satz
  • Kopf bestimmt die Phrasenkategorie (Wortart X → Phrasenkat. XP)

Beispiel Phrasenkopf

  • in der Verbalphrase fährt im rote Auto davon ist das Verb fährt der Kopf der Phrase
  • die PP im roten Auto und die Adverbialphrase ADVP davon sind Adjunkte der VP
  • fährt kann auch alleine eine VP bilden: Er fährt.
  • das Subjektagreement wird alleine vom Verb gesteuert:
    Er fährt davon. vs. Sie fahren davon.

短语中心语: 短语里的所有词和短语都依存于中心语; 中心语把形态句法特征 (格等) 传给短语; 中心语控制该成分在句中的句法行为; 中心语决定短语范畴 (词类 X → 短语范畴 XP). 例: 在动词短语 fährt im roten Auto davon (开着红色的车离去) 中, 动词 fährt 是中心语; PP im roten Auto 和副词短语 davon 是 VP 的附加语; fährt 也可以单独构成 VP: Er fährt. 主语一致只由动词控制: Er fährt davon / Sie fahren davon.

四条性质可以记成「依存、传特征、控行为、定类别」. 「X → XP」: 名词的短语是 NP, 介词的短语是 PP, 这就是名称的来源.

中心语渗透
Kopf-Perkolation

Folie 26

Kopf-Perkolation

  • Köpfe werden im Syntaxbaum nach oben weitergereicht (da hierarchische Struktur, Phrasen in andere eingebettet)
  • wichtig u.a. für lexikalisierte Grammatiken sowie die Transformation einer Phrasenstruktur- in eine Dependenzgrammatik

Kopf-Perkolations-Regeln

  • head(S) = head(VP)
    → Kopf von S ist Kopf von VP
  • head(VP) = head(V)
  • head(V) = jagt

Kopf-Perkolation 中心语渗透: 中心语在句法树中被向上传递 (因为结构是层级的, 短语嵌在别的短语里); 这对词汇化文法以及把短语结构文法转换成依存文法很重要. 渗透规则: S 的中心语 = VP 的中心语; VP 的中心语 = V 的中心语; V 的中心语 = jagt.

形式文法
Formale Grammatik

Folie 36

Formale Grammatik

  • mathematisches Regelsystem, das verwendet wird, um eine formale Sprache eindeutig zu beschreiben und zu erzeugen
  • dient zur Generierung aller wohlgeformten Ausdrücke einer Sprache und wird oft als generative Grammatik bezeichnet

Ableitungsregeln

  • eine formalen Grammatik verwendet Ableitungsregeln (auch Produktionsregeln), die von einem Startsymbol ausgehend
    • die linke Regelseite (LHS = left-hand side)
    • durch die rechte Regelseite (RHS = right-hand side) ersetzen

Formale Grammatik zur Syntaxanalyse

  • neben der Erzeugung formaler Sprachen kann eine formale Grammatik auch als Modell zur Erkennung und Analyse der syntaktischen Struktur natürlicher Sprachen dienen

形式文法: 一种数学规则系统, 用来无歧义地描述和生成一种形式语言; 用于生成一种语言的所有合格表达式, 因此常被称为generative Grammatik 生成文法. 推导规则: 形式文法使用推导规则 (也叫Produktionsregel 产生式规则), 从一个Startsymbol 起始符号出发, 把规则的左边 (LHS) 替换成规则的右边 (RHS). 用于句法分析的形式文法: 除了生成形式语言, 形式文法还能作为识别和分析自然语言句法结构的模型.

原文笔误: 「eine formalen Grammatik verwendet …」: 主格不定冠词后应为 eine formale Grammatik.

形式语言
Formale Sprache

Folie 37

Formale Sprache

  • Menge aller Ausdrücke, die mithilfe der Regeln einer formalen Grammatik aus Nichtterminalsymbolen abgeleitet werden können
  • wobei die Ausdrücke aus den Grundsymbolen der Sprache bestehen

Grundsymbole (Terminalsymbole)

  • z. B. {a, b, c}
  • in Modellierung natürlicher Sprache: Wörter des Lexikons, z. B. {die, der, den, Hund, Katze, jagt}

Ableitbare Ausdrücke

  • z. B. {a, aa, aba, abcc, ...}
  • = formalsprachliche Wörter (die Blätter des Ableitungsbaums)
  • in Modellierung natürlicher Sprache: natürlichsprachliche Sätze, z. B. {”der Hund jagt die Katze”, ”die Katze jagt den Hund”, ...}

形式语言 = 能借助形式文法的规则从非终端符号推导出来的所有表达式的集合, 这些表达式由该语言的基本符号组成. 基本符号 (Terminalsymbol 终端符号): 如 {a, b, c}; 在为自然语言建模时就是词汇表里的词, 如 {die, der, den, Hund, Katze, jagt}. 可推导的表达式: 如 {a, aa, aba, abcc, …} = 形式语言意义上的「词」(推导树的叶子); 在为自然语言建模时就是自然语言的句子.

易错 (术语错位): 形式语言学里的「Wort 词」= 一串终端符号; 对应到自然语言, 它是一个句子. 而形式语言学的「字母表 (终端符号)」对应自然语言的词. 别把两个「词」混起来.

严格地说, 形式语言是从起始符号 (一个特定的非终端符号) 推导出的、只含终端符号的串的集合. 幻灯片说「aus Nichtterminalsymbolen」是笼统的说法: 从任意一个非终端符号出发推导出的是该范畴的语言 (例如从 NP 出发得到所有名词短语), 只有从 S 出发得到的才是「句子的语言」.

3.2 上下文无关文法
3.2. Kontextfreie Grammatik

乔姆斯基层级
Chomsky-Hierarchie

Folie 40–41

Typ 0: Unbeschränkte Grammatiken (Rekursiv aufzählbar)

  • Regeln der Form α → β, wobei α, γ beliebige Folge von Terminal- und Nichtterminalsymbolen

Typ 1: Kontextsensitive Grammatiken

  • Regeln der Form αAβ → αγβ, wobei A ein Nichtterminal ist (α, β, γ beliebig)

Typ 2: Kontextfreie Grammatiken (CFG)

  • Regeln der Form A → γ, wobei A ein Nichtterminal ist (γ beliebig)
  • Beschränkung: links (LHS) genau ein Nichtterminal, rechts (RHS) beliebig

Typ 3: Reguläre Grammatiken

  • Einfachste Art von Grammatiken (am stärksten beschränkt)
  • Regeln der Form A → αB, wobei A und B Nichtterminale und α eine Folge von Terminalsymbolen sind.
  • Weitere Beschränkung: rechts (RHS) nur ein Nichtterminal möglich!
  • 0 型: 无限制文法 (递归可枚举): 规则形如 α → β, α、β 是终端和非终端符号的任意序列.
  • 1 型: 上下文有关文法: 规则形如 αAβ → αγβ, A 是一个非终端符号 (α、β、γ 任意). A 只有在左边是 α、右边是 β 的「上下文」里才能被替换成 γ.
  • 2 型: 上下文无关文法: 规则形如 A → γ, A 是一个非终端符号 (γ 任意). 限制: 左边恰好一个非终端符号, 右边任意. 「上下文无关」= 替换 A 时不看它周围是什么.
  • 3 型: 正则文法: 最简单的文法 (限制最强); 规则形如 A → αB, A 和 B 是非终端符号, α 是终端符号序列; 进一步的限制: 右边最多只能有一个非终端符号 (而且在最右边).

例子: S → NP VP 是 2 型规则 (右边两个非终端, 不是正则的); NP → der N 也不是正则的 (非终端不在最右); NP → der N1, N1 → Hund 是正则的.

幻灯片错误: 0 型的说明「wobei α, γ beliebige Folge …」与规则 α → β 不符, 应为 α, β. 另外 0 型通常还要求左边 α 至少含一个非终端符号 (否则可以把终端符号替换掉, 推导就没有意义).

幻灯片错误: 3 型只给出 A → αB 一种规则形式. 只用这种规则, 每一步推导后串里永远还剩一个非终端符号 B, 推导永远不会结束, 一个句子都生成不出来. 正则文法还必须允许 A → α (右边只有终端符号) 这种结束规则. 所以「rechts nur ein Nichtterminal möglich」应理解为「最多一个」.

  • Typ 0 (rekursiv aufzählbar, Turingmaschinen) ist am ausdrucksfähigsten
  • die Ausdrucksfähigkeit nimmt mit jedem Typ ab
  • Typ 3 (regulär, endliche Automaten) ist am stärksten eingeschränkt

短语结构文法
Phrasenstrukturgrammatik

Folie 43

Kontextfreie Grammatik als Phrasenstrukturgrammatik (PSG)

  • Chomsky: die Konstituenten- bzw. Phrasenstruktur natürlicher Sprache ist formal beschreibbar durch kontextfreie Grammatiken
  • Strukturregeln der (auch rekursiven) Kombination von lexikalischen und phrasalen Kategorien zu phrasalen Kategorien und Sätzen
    • z.B. S → NP VP, NP → DET ADJ N

Syntaktische Regeln (NP → DET N PP)
bestimmen, zu welchen Klassen die unmittelbaren Konstituenten (RHS) einer syntaktischen Kategorie (LHS) gehören (LHS+RHS jeweils Nichtterminalsymbole)

Lexikalische Regeln (N → Hund)
bestimmen die Zugehörigkeit einer elementaren Konstituente (RHS) (= Wort, Terminalsymbol) zu einer lexikalischen Kategorie (LHS) (= Wortart, Nichtterminalsymbol, manchmal auch Präterminalsymbol genannt)

上下文无关文法作为Phrasenstrukturgrammatik 短语结构文法 (PSG): 乔姆斯基认为, 自然语言的成分结构 (短语结构) 可以用上下文无关文法形式化地描述; 规则是把词汇范畴和短语范畴 (也可以递归地) 组合成短语范畴和句子的结构规则, 如 S → NP VP、NP → DET ADJ N. 句法规则 (NP → DET N PP): 规定一个句法范畴 (左边) 的直接成分 (右边) 属于哪些类 (左右两边都是非终端符号). 词汇规则 (N → Hund): 规定一个基本成分 (右边, 即词、终端符号) 属于哪个词汇范畴 (左边, 即词类、非终端符号, 有时也叫前终端符号).

CFG 短语结构文法的例子
Beispiel einer CFG-Phrasenstrukturgrammatik

Folie 44 
1 ###### Syntaktische Regeln ######
2 S → NP VP
3 NP → DET N
4 VP → V NP NP
5
6 ###### Lexikalische Regeln ######
7 DET → "der" | "die" | "das"
8 N → "Mann" | "Frau" | "Buch"
9 V → "gibt" | "schenkt"

3 条句法规则 + 3 条 (带 | 的) 词汇规则. VP → V NP NP 是双宾语结构: geben 要求主语、间接宾语 (三格) 和直接宾语 (四格). 例句: der Mann gibt der Frau das Buch (那个男人把书给那个女人).

在 NLTK 里要把箭头写成 ->, 用 CFG.fromstring 读入 (幻灯片的 → 是排版效果). 完整可运行的写法:

import nltk
grammar = nltk.CFG.fromstring("""
S -> NP VP
NP -> DET N
VP -> V NP NP
DET -> "der" | "die" | "das"
N -> "Mann" | "Frau" | "Buch"
V -> "gibt" | "schenkt"
""")
parser = nltk.ChartParser(grammar)
sent = "der Mann gibt der Frau das Buch".split()

这份文法太宽松: 它不检查格和性. 我用 NLTK 枚举了它能生成的所有句子, 共 1458 个 (3 × 3 种主语 × 2 个动词 × 9 × 9 种宾语), 其中包括 *die Mann gibt das Frau der Buch 这样的错句. 要排除它们, 就要给范畴加上性、数、格特征, 这就是课程后面要讲的 FCFG.

短语结构文法的组成
Aufbau Phrasenstrukturgrammatik

Folie 46

Grammatikdefinition

  • Startsymbol: S
  • Nichtterminalsymbole: NP, VP, DET, N, V
  • Terminalsymbole: der, Hund, schläft
  • Produktionsregeln: S → NP VP, NP → DET N, VP → V

Hinweise zur Grammatik

  • Ersetzungsregeln (linke mit rechter Seite)
  • CFG-Regel-Einschränkung (Chomsky-Hierarchie):
    • links nur ein Nichtterminalsymbol
      → Ersetzung unabhängig von Kontext (Kontextfreiheit)

文法定义: 起始符号 S; 非终端符号 NP、VP、DET、N、V; 终端符号 der、Hund、schläft; 产生式规则 S → NP VP、NP → DET N、VP → V. 说明: 规则是替换规则 (用右边替换左边); CFG 的规则限制 (乔姆斯基层级): 左边只有一个非终端符号 → 替换与上下文无关 (上下文无关性).

幻灯片小错: 这份文法定义不完整: 列出了终端符号 der、Hund、schläft, 但产生式规则里只有三条句法规则, 没有把它们挂上的词汇规则 (DET → der, N → Hund, V → schläft). 照原样, 这个文法一个句子都推导不出来. 补上三条词汇规则后, 它只生成一句: der Hund schläft. 另外 S 本身也是非终端符号, 列表里没有写.

短语结构规则作为产生式规则
PSG-Regeln als Produktionsregeln

Folie 47
  • PSG-Regeln können als Konstruktionsanweisung für Syntaxbäume interpretiert werden:
    S → NP VP als ’expandiere S zu Folge NP + VP’
  • PSG-Regel definiert Relation der unmittelbaren Dominanz zwischen Mutterknoten und Tochterknoten
    → ’S dominiert unmittelbar NP und VP’
    → ’S dominiert vollständig die Folge NP + VP’
    → und: ’NP und VP sind Ko-Konstituenten’ (Geschwisterknoten)
  • PSG erkennt durch Ableitung Sätze als zur Sprache gehörig und weist ihnen die ihren Regeln entsprechende Strukturbeschreibung zu
    → Strukturbeschreibung = die auf Kategorien bezugnehmende Konstituentenstruktur
    → ’Die Folge NP + VP ist ein S’

短语结构规则可以理解为构造句法树的指令: S → NP VP 意思是「把 S 展开为序列 NP + VP」. 一条 PSG 规则定义了母节点和子节点之间的直接支配关系: 「S 直接支配 NP 和 VP」;「S 完整地支配序列 NP + VP」; 以及「NP 和 VP 是并列成分 (Geschwisterknoten 兄弟节点)」. PSG 通过推导识别句子属于该语言, 并给它们指派与规则对应的结构描述 → 结构描述 = 以范畴为单位的成分结构 → 「序列 NP + VP 是一个 S」.

同一条规则有两种读法: 自上而下是「S 展开成 NP VP」(生成); 自下而上是「NP VP 合起来是 S」(识别). 这正是 SNS 01 里 parser 的两项任务.

析取运算符
Disjunktionsoperator

Folie 48

Disjunktionsoperator

  • der Disjunktionsoperator | wird verwendet, um alternative Ableitungen auszudrücken
  • Abkürzung für zwei Regeln mit der selben LHS
  • kann in den CFGs von NLTK verwendet werden

Beispiel

  • NP → DET N | DET ADJ N
  • äquivalent zu:
    NP → DET N
    NP → DET ADJ N

Konvention für fakultative Elemente

  • im Beispiel ist ADJ fakultativ
  • kann auch folgendermaßen geschrieben werden: NP → DET (ADJ) N

析取运算符 | 用来表示可选的不同推导; 是左边相同的两条规则的简写; NLTK 的 CFG 里可以用. 例: NP → DET N | DET ADJ N 等价于两条规则 NP → DET N 和 NP → DET ADJ N. 可选成分的约定: 例子中 ADJ 是可选的, 也可以写成 NP → DET (ADJ) N.

易错: 括号写法 (ADJ) 只是语言学书里的约定, NLTK 不支持; 在 NLTK 里只能写成 NP -> DET N | DET ADJ N. 同理, 这和 EBNF 里的 [ ] 可选符号是同一个意思.

推导作为自顶向下的生成
Ableitung als top-down Erzeugung

Folie 49

Formale Definition einer kontextfreien Grammatik

G (Grammatik) = < T (Terminale), N (Nichtterminale), S (Startsymbol), R (Regeln) >

Beispielableitung

G = < {das, Tier, Futter, sieht}, {S, NP, VP, DET, N, V}, S, R >
R = {S → NP VP, NP → DET N, VP → V NP, DET → das, N → Tier, N → Futter, V → sieht}

S  ⇒  NP VP                    (S → NP VP)
   ⇒  DET N VP                 (NP → DET N)
   ⇒  das N VP                 (DET → das)
   ⇒  das Tier VP              (N → Tier)
   ⇒  das Tier V NP            (VP → V NP)
   ⇒  das Tier sieht NP        (V → sieht)
   ⇒  das Tier sieht DET N     (NP → DET N)
   ⇒  das Tier sieht das N     (DET → das)
   ⇒  das Tier sieht das Futter (N → Futter)

上下文无关文法的形式定义: 四元组 G = ⟨T 终端符号集, N 非终端符号集, S 起始符号, R 规则集⟩. 推导示例: 从 S 出发, 每一步用一条规则替换一个非终端符号, 括号里是所用的规则, 9 步得到「das Tier sieht das Futter」(动物看见饲料).

这里每一步都替换最左边的非终端符号, 叫最左推导 (SMIS 课也会讲). 每一步「⇒」读作「直接推导出」. 用 NLTK 枚举这份文法, 它一共能生成 4 个句子: das Tier/Futter sieht das Tier/Futter.

易错: 文法四元组里 N 是「非终端符号集」, 同时规则里又有词类 N (Nomen). 两个 N 不是一回事.

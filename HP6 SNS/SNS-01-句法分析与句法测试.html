1. 作为句法分析的 Parsing
1. Parsing als Syntaxanalyse

Parsing 作为自动句法分析
Parsing als automatische Syntaxanalyse

Folie 2–3

Aufgaben eines Parsingalgorithmus

  1. Überprüfung der grammatischen Struktur einer Eingabe auf Wohlgeformtheit
    → Suche einer Ableitung gemäß der Regeln einer formalen Grammatik
  2. Wiedergabe der gefundenen grammatischen Struktur
    → Ableitungsbaum (auch: Parsebaum, Syntaxbaum)

句法分析算法 (Parsingalgorithmus 句法分析算法) 的任务: ① 检查输入的语法结构是否合格 → 按照形式文法的规则寻找一个推导; ② 输出找到的语法结构 → 推导树 (也叫: 分析树、句法树).

一个 parser 同时回答两个问题: 「这句话合不合语法?」(是/否) 和「如果合, 它的结构是什么?」(一棵树). 第一个问题只要找到一个推导就能回答「是」; 第二个问题要把这个推导画成树. 遇到歧义句时, 会找到不止一棵树.

Folie 4

Verarbeitung formaler Grammatiken

  • Formale Grammatik = Syntaktisches Strukturmodell
    → dessen Regeln sind aber nicht mehr als Sammlung von Strings
  • Verfahren notwendig, um zu entscheiden, ob eine Eingabe gemäß einer gegebenen formalen Grammatik wohlgeformt ist

Parsing-Algorithmen

  • Verfahren zur Verarbeitung von formalen Grammatiken zur Strukturerkennung und -Analyse der Eingabe (Satz als Tokensequenz)

形式文法的处理: 形式文法 = 句法结构模型 → 但它的规则只不过是一堆字符串; 需要一种方法来判定一个输入按照给定的形式文法是否合格. 句法分析算法: 处理形式文法的方法, 用来识别和分析输入 (作为词符序列的句子) 的结构.

理解要点: 文法本身是静态的「规则清单」, 它不会自己去检查句子. 要有一个程序 (算法) 拿着规则去试, 这个程序就是 parser. 同一份文法可以配不同的 parser (自顶向下、自底向上、chart parser 等, NLTK 都有).

Strukturerkennung

Grammatik-Typen

Folie 6

Haupttypen

  1. CFGs (kontextfreie Grammatiken)
    • Konstituentenstruktur (Phrasenstrukturgrammatik)
    • Strukturinformationen in den Knoten des Syntaxbaums
  2. Dependenzgrammatiken
    • Abhängigkeitsrelationen zwischen Wörtern
    • Strukturinformationen in den Kanten des Syntaxbaums (Relationslabel)
  3. Chunk-Parser (u.a. reguläre Grammatiken)
    • partielle Syntaxanalyse (nur wichtigste Konstituenten: NPs, VPs, PPs)
    • flache, nicht-hierarchische Strukturanalyse

Erweiterungen von CFGs

  1. PCFGs = Probabilistische CFGs
  2. FCFGs = Feature-basierte CFGs

主要类型: ① CFG (上下文无关文法): 成分结构 (短语结构文法), 结构信息在句法树的节点里; ② 依存文法: 词之间的依存关系, 结构信息在句法树的边上 (关系标签); ③ 组块分析器 (Chunk-Parser, 包括正则文法): 部分句法分析 (只找最重要的成分: NP、VP、PP), 扁平的、非层级的结构分析. CFG 的扩展: PCFG = 概率 CFG; FCFG = 基于特征的 CFG.

类型结构信息在哪里输出
CFG节点 (NP, VP …)完整的层级树
依存文法边 (subj, obj …)词与词的依存树
Chunk-Parser只有一层组块扁平: [NP der Hund] [VP jagt] [NP die Katze]

易错: PCFG 和 FCFG 不是新的文法类型, 而是 CFG 加上东西: PCFG 给每条规则一个概率 (用来在歧义中选最可能的树), FCFG 给范畴加特征 (如数、格, 用来检查一致).

2. 句法单位的分析
2. Analyse syntaktischer Einheiten

结构主义的分析方法
Strukturalistische Analysemethoden

Folie 8–9

Segmentierung: Feststellung syntaktischer Einheiten

  • Zerlegung Satz in Konstituenten
    → Konstituenten = sprachliche Einheiten, die Teile einer größeren Einheit sind (insbes. Wörter, Phrasen oder Teilsätze)
  • Analyse syntagmatischer Beziehung zwischen Einheiten
  • zusammengehörende Elemente feststellbar über Konstituententests

Klassifizierung: Feststellung syntaktischer Kategorien

  • syntaktische Kategorien = Mengen syntaktischer Einheiten mit gleichen Eigenschaften (Klassen)
  • morphologische, syntaktische und semantische Klassifizierungskriterien
    • syntaktisches Kriterium: Austauschbarkeit im gleichen Kontext
  • Analyse paradigmatischer Beziehung zwischen Einheiten

Segmentierung 切分 = 确定句法单位: 把句子拆成Konstituente 成分 (成分 = 作为更大单位一部分的语言单位, 特别是词、短语或分句); 分析单位之间的syntagmatisch 组合关系; 哪些元素属于一起, 可以用成分测试确定. Klassifizierung 分类 = 确定句法范畴: 句法范畴 = 具有相同性质的句法单位的集合 (类); 分类标准有形态的、句法的和语义的, 句法标准是「在同一语境中可替换」; 分析单位之间的paradigmatisch 聚合关系.

结构主义分析分两步: 先切 (哪些词组成一个单位), 再归类 (这个单位属于哪一类, NP 还是 PP). 切分看的是横向的组合关系, 归类看的是纵向的替换关系, 下一页用图示对比.

组合维度与聚合维度
Syntagmatische vs. paradigmatische Dimension

Folie 10
syntagmatischparadigmatisch
lineare Kombinierbarkeitvertikale Austauschbarkeit

der { große | kleine } Hund jagt { die Katze. | Ferdinand. }

Ein großer { Hund | *Ferdinand } jagt die Katze.

{ Sie | die sich im Gehen nach dem Hund umschauende Frau } stürzt.

Er { sieht einen Hund | geht } auf dem Weg.     Er { sieht | *geht } einen Hund.

(Auf der Folie stehen die Alternativen untereinander in geschweiften Klammern; hier durch „|“ getrennt.)

组合的 (syntagmatisch) = 线性的可组合性; 聚合的 (paradigmatisch) = 纵向的可替换性. 花括号里竖着排列的是可以在同一位置互相替换的成分.逐例讲解:

  • der {große | kleine} Hund jagt {die Katze | Ferdinand}: große 和 kleine 能互换 → 同属形容词; 「die Katze」(两个词) 和「Ferdinand」(一个专名) 能互换 → 同属 NP, 尽管长度不同.
  • Ein großer {Hund | *Ferdinand} jagt die Katze: 在「ein großer ___」这个位置上普通名词可以, 专名不行 → 专名和普通名词在这个语境里不可互换, 所以要分成两类 (NN 与 NE).
  • {Sie | die sich im Gehen nach dem Hund umschauende Frau} stürzt: 一个代词能替换一个很长的名词短语 → 二者是同一类单位 (NP). 「她摔倒了」/「那个边走边回头看狗的女人摔倒了」.
  • Er {sieht einen Hund | geht} auf dem Weg: 「sieht einen Hund」(及物动词 + 宾语) 能整体换成不及物动词 geht → 二者都是 VP. 但 Er {sieht | *geht} einen Hund: 单独的 geht 不能带宾语 → sieht 和 geht 虽然都是动词, 却不能在这里互换, 说明动词还要按配价细分 (及物 / 不及物).

能否在同一语境里互相替换, 就是分类的句法标准 (Folie 9). 下划线标的是各成分的中心语: 替换以后中心语的类别决定整体的类别.

3. 成分测试
3. Konstituententests

识别成分的方法
Methoden zur Identifizierung von Konstituenten

Folie 11–12

Konstituententests

  • zur Feststellung syntagmatischer Einheiten (Konstituenten)
  • Konstituenten-Hierarchie: unmittelbare vs. mittelbare Konstituenten

Hauptkriterien

Ersetzbarkeit und Verschiebbarkeit unter Erhalt der Grammatikalität

Konstituententest 成分测试用来确定组合单位 (成分); 成分有层级: unmittelbare 直接成分与mittelbare 间接成分. 主要标准: 在保持合语法性的前提下, 能否替换、能否移位.

直接 vs. 间接成分: 句子 [Der Junge] [verkauft die Äpfel des Bauern] 的直接成分是这两块; die Äpfel des Bauern 是 VP 的一部分, 对句子来说是间接成分. 树里: 母节点的直接子节点 = 直接成分.

下面四种测试各占一节: 替换、移位、删除、并列. 每种测试都在同一个句子 Der Junge verkauft die Äpfel des Bauern (那个男孩卖农夫的苹果) 上演示.

3.1 替换测试
3.1. Substitutionstest

Folie 13–14

auch: Ersatzprobe

  • eine unter Erhalt der Grammatikalität des Satzes durch eine andere Wortfolge ersetzbare Wortfolge ist Konstituente
  • Feststellung von Einheiten (Austauschbarkeit im gleichen Kontext; allgemeiner: auch für Wortarten, Flexionsparadigmen)
  • Pronominalisierung
    → Eine durch Pronomen ersetzbare Wortfolge ist Konstituente
  • für Feststellung Verb mit Erweiterungen (komplexe VP) als Konstituente
    → Ersatz komplexer VP durch (intransitives) Verb

又叫 Ersatzprobe 替换测试. 一个词串如果能被另一个词串替换而句子仍合语法, 它就是成分. 用来确定单位 (同一语境中可替换; 更广义地也用于词类、屈折变化表). Pronominalisierung 代词化: 能被代词替换的词串是成分. 用来确定「动词 + 扩展」(复杂 VP) 是成分: 把复杂 VP 换成一个 (不及物) 动词.

Folie 15

Der Junge verkauft die Äpfel des Bauern.

Identifizierung der Wortfolgen der Junge und die Äpfel des Bauern als Konstituenten durch Pronominalisierung:

Er verkauft sie.

Identifizierung der Wortfolge verkauft die Äpfel des Bauern als komplexe VP-Konstituente durch Ersatz mit intransitivem Verb:

Der Junge arbeitet.

「der Junge」换成 er, 「die Äpfel des Bauern」换成 sie → 两者都是成分 (NP). 「verkauft die Äpfel des Bauern」整体换成不及物动词 arbeitet (工作) → 动词加宾语是一个成分 (VP).

易错: 代词替换的是整个名词短语. 只把 Äpfel 换成 sie (*der Junge verkauft die sie des Bauern) 不合语法, 说明 Äpfel 单独不是 NP. 代词化找到的是完整的名词短语; 名词短语内部的结构 (如 des Bauern) 要靠后面的删除测试和并列测试.

3.2 移位测试
3.2. Permutationstest

Folie 16–17

auch: Verschiebeprobe

  • eine im Satz ohne Zerstörung der Grammatikalität verschiebbare Wortfolge ist Konstituente
  • im Deutschen: Verschiebung vor finites Verb (ins sog. Vorfeld)
    → Topikalisierung: rhetorisch-pragmatische Funktion
  • Verwendung zum Testen von Wortstellungsmöglichkeiten

auch: Auflösung von Ambiguität

  • Der Junge beobachtete das Mädchen mit dem Fernglas.  (ambig)
  • Das Mädchen mit dem Fernglas beobachtete der Junge.  (NP-Attr.)
  • Mit dem Fernglas beobachtete der Junge das Mädchen.  (VP-Adj.)

又叫 Verschiebeprobe 移位测试. 一个词串如果能在句中挪动位置而不破坏合语法性, 它就是成分. 在德语里: 挪到限定动词前面 (所谓Vorfeld 前场) → Topikalisierung 话题化: 有修辞-语用功能. 用于测试可能的词序. 也能消解歧义.

歧义例子: 「Der Junge beobachtete das Mädchen mit dem Fernglas」有两个意思: ① 男孩用望远镜观察女孩 (mit dem Fernglas 修饰动词 = VP 附加语); ② 男孩观察那个拿着望远镜的女孩 (修饰 das Mädchen = NP 定语). 移位后歧义消失: 把「das Mädchen mit dem Fernglas」整体移到前场, 说明它们是一个成分 → 读法 ②; 只把「mit dem Fernglas」移到前场 → 它是独立成分, 修饰动词 → 读法 ①.

德语特点: 德语陈述句是「动词第二位」(V2): 限定动词前面正好只能站一个成分. 所以「能放进前场」几乎就等于「是一个句子成分 (Satzglied)」, 这个测试在德语里特别好用.

Folie 18

Der Junge verkauft die Äpfel des Bauern.

Identifizierung der Wortfolgen der Junge und die Äpfel des Bauern als Konstituenten durch Permutation:

Die Äpfel des Bauern verkauft der Junge.

宾语「die Äpfel des Bauern」移到前场, 主语「der Junge」随之移到动词后: 两块都能整体挪动 → 都是成分. 意思不变 (仍是男孩卖苹果, 格标记 der Junge = 主格保证了这一点), 只是强调了苹果.

3.3 删除测试
3.3. Eliminierungstest

Folie 19–20

auch: Weglassprobe

  • eine ohne Zerstörung der Grammatikalität eines Satzes weglassbare Wortfolge ist Konstituente
  • Feststellung syntaktisch weglassbarer bzw. optionaler Einheiten
    • (s.u. Eliminierungstest als Adjunkt-Test)

又叫 Weglassprobe 删除测试. 一个词串如果能删去而句子仍合语法, 它就是成分. 用来确定句法上可省略的 (即可选的) 单位 (见下文: 删除测试作为附加语测试).

Folie 21

Der Junge verkauft die Äpfel des Bauern.

Identifizierung der Wortfolge des Bauern als attributive Konstituente (nominales Adjunkt) durch Eliminierung:

Der Junge verkauft die Äpfel.

删去「des Bauern」后句子仍然合语法 → 它是一个成分, 而且是定语性成分 (名词的附加语, 修饰 Äpfel).

易错: 删除测试只能找出可以省略的成分. 主语「der Junge」是成分, 但删掉它 (*verkauft die Äpfel des Bauern) 句子就坏了. 所以删除测试失败不说明它不是成分; 它测的其实是「可选性」.

3.4 并列测试
3.4. Koordinationstest

Folie 22–23

Koordination: Verbindung mit und / aber

  • eine mit einer anderen Wortfolge unter Erhalt der Grammatikalität des Satzes koordinierbare Wortfolge ist Konstituente
  • geeignet für die Ermittlung von Phrasenteilen (Attributen usw.)
  • Analyse der Struktur von komplexen Konstituenten

Konstituenten müssen vom gleichen Typ sein

  • Er schrieb einen Brief und eine Karte.
  • Er schrieb an dich und an mich.
  • aber nicht: *Er schrieb einen Brief und an mich.

Koordination 并列 = 用 und / aber 连接. 一个词串如果能和另一个词串并列而句子仍合语法, 它就是成分. 适合找出短语内部的部分 (定语等), 分析复杂成分的结构. 并列的成分必须类型相同: 「他写了一封信和一张卡片」(NP + NP)、「他写给你和给我」(PP + PP) 可以; 「*他写了一封信和给我」(NP + PP) 不行.

并列测试同时检验两件事: 是不是成分, 以及属于哪一类. 「einen Brief」和「an mich」各自都是成分, 但类型不同, 所以不能并列.

Folie 24

Der Junge verkauft die Äpfel des Bauern.

Identifizierung der Wortfolge des Bauern als Konstituente durch Koordination:

Der Junge verkauft die Äpfel des Bauern und der Bäuerin

Konstituentenstruktur als Ergebnis aller Konstituententests

「des Bauern」可以和「der Bäuerin」(农妇的, 同为二格 NP) 并列 → 它是成分. 综合所有测试得到的成分结构 (逐层二分):

  • Der Junge verkauft die Äpfel des Bauern → [Der Junge] [verkauft die Äpfel des Bauern]
  • verkauft die Äpfel des Bauern → [verkauft] [die Äpfel des Bauern]
  • die Äpfel des Bauern → [die Äpfel] [des Bauern]

对照各测试: 主语和宾语来自代词化与移位; VP 来自替换成 arbeitet; des Bauern 来自删除和并列.

原文小错: 并列例句「Der Junge verkauft die Äpfel des Bauern und der Bäuerin」句末少了句号 (前面所有例句都有).

4. 补足语/附加语测试
4. Komplement/Adjunkt-Tests

区分补足语与附加语的方法
Methoden zur Komplement/Adjunkt-Unterscheidung

Folie 25–26
  • neben den Konstituententests gibt es weitere syntaktische Tests, die der Unterscheidung notwendiger von nicht-notwendigen Satzgliedern dienen (Komplement vs. Adjunkt)
    • als Satzglieder werden in der Germanistik die im Satz verschiebbaren (permutierbaren) Konstituenten mit zentraler syntaktischer Funktion (Subjekt, Objekt, Prädikat, Adverbial) bezeichnet, in die ein Satz unmittelbar zerlegt werden kann
  • Komplement:
    • notwendiges Satzglied
    • Auftreten ist von Kopf gefordert (valenzgefordert)
    • z.B. Subjekt, Objekt als Verb-Komplemente: die Katze sieht einen Hund, nicht: *sieht einen Hund
  • Adjunkt:
    • nicht-notwendiges Satzglied
    • Auftreten ist nicht von Kopf gefordert
    • z.B. Adjektiv-Attribut als Adjunkt des Nomens: das rote Auto
    • z.B. PP-Adverbial als Adjunkt des Verbs: er läuft im Park

除了成分测试, 还有其他句法测试, 用来区分必需的和非必需的句子成分 (补足语 vs. 附加语). 在德语语言学中, Satzglied 句子成分指的是: 句子能直接拆成的、可以在句中移位的、承担核心句法功能 (主语、宾语、谓语、状语) 的成分. Komplement 补足语: 必需的句子成分, 它的出现由中心语要求 (valenzgefordert 配价要求的); 例如作为动词补足语的主语和宾语: 「die Katze sieht einen Hund」, 不能说「*sieht einen Hund」. Adjunkt 附加语: 非必需的句子成分, 它的出现不是中心语要求的; 例如作为名词附加语的形容词定语「das rote Auto」, 作为动词附加语的介词短语状语「er läuft im Park」.

判断标准是「中心语要不要它」. sehen 是二价动词, 必须有看的人和被看的东西, 所以二者是补足语. laufen 不要求地点, im Park 可有可无, 所以是附加语. 附加语的个数没有上限 (er läuft im Park, am Morgen, schnell …), 补足语的个数由动词的配价固定.

geschehen 测试
geschehens-Test

Folie 27
  • Auslagerung des Satzglieds in einen Satz mit dem Verb geschehen.
    • wenn Grammatikalität erhalten ⇒ Adjunkt
    • wenn Grammatikalität nicht erhalten ⇒ Komplement

Er wartete im Park auf die Katze.
Er wartete auf die Katze, und das geschah im Park. (Adjunkt)
*Er wartete im Park, und das geschah auf die Katze. (Komplement)

把这个句子成分移出去, 放进一个以 geschehen (发生) 为动词的句子. 若仍合语法 ⇒ 附加语; 若不合语法 ⇒ 补足语. 例: 「他在公园里等那只猫」→「他等那只猫, 这件事发生在公园里」(合语法 → im Park 是附加语); 「*他在公园里等, 这件事发生在那只猫」(不合语法 → auf die Katze 是补足语, 介词宾语).

原理: 附加语描述的是整个事件的情况 (地点、时间、方式), 所以可以说「这件事发生在…」. 补足语是动词本身意义的一部分 (warten auf: 等「谁」), 离开动词就无法单独描述事件.

状语从句测试
Adverbialsatz-Test

Folie 28
  • Auslagerung des Satzglieds in einen Adverbialsatz (funktioniert nicht bei Zeitangaben).
    • wenn Grammatikalität erhalten ⇒ Adjunkt
    • wenn Grammatikalität nicht erhalten ⇒ Komplement (oder temporales Adjunkt! = Zeitangabe)

Er wartete im Park auf die Katze.
Er wartete auf die Katze, als er im Park war. (Adjunkt)
*Er wartete im Park, als er auf die Katze war. (Komplement)

*Er wartete auf die Katze, als er bis Mitternacht war. (temporales Adjunkt)

把句子成分移进一个状语从句 (「als er … war」= 当他在…的时候); 对时间状语不适用. 若合语法 ⇒ 附加语; 若不合语法 ⇒ 补足语 (或者时间附加语!). 例: 「他等那只猫, 当他在公园里的时候」(合语法, 附加语); 「*他在公园里等, 当他在那只猫的时候」(补足语); 「*他等那只猫, 当他在到午夜的时候」(不合语法, 但 bis Mitternacht 其实是时间附加语).

易错: 这个测试失败时不能直接下结论是补足语, 因为时间状语也会失败: 「als er … war」这个框架要求一个「在某处/处于某状态」的表达, 时间段放不进去. 遇到时间状语要改用 geschehen 测试 (… und das geschah bis Mitternacht 是可以的).

删除测试 (作为附加语测试)
Eliminierungstest

Folie 29
  • Eliminierung des Satzglieds (Feststellung ihrer Weglassbarkeit).
    • wenn Grammatikalität erhalten ⇒ Adjunkt (oder fakultatives Komplement!, s.u.)
    • wenn Grammatikalität nicht erhalten ⇒ Komplement

Er beantwortet einen Brief im Arbeitszimmer.
Er beantwortet einen Brief im Arbeitszimmer. (Adjunkt)
*Er beantwortet einen Brief im Arbeitszimmer. (Komplement)

Er schreibt einen Brief im Arbeitszimmer. (fakultatives Komplement)

删去这个句子成分 (检验能否省略). 若仍合语法 ⇒ 附加语 (或者可选补足语!, 见下页); 若不合语法 ⇒ 补足语. 例: 「他在书房里回一封信」: 删去 im Arbeitszimmer 仍合语法 → 附加语; 删去 einen Brief 得到「*他在书房里回复」, 不合语法 → 补足语 (beantworten 必须有宾语). 但「他在书房里写 (一封信)」: 删去 einen Brief 仍合语法, 可 einen Brief 是 schreiben 的宾语 → 可选补足语.

易错: 删除测试成功时不能直接下结论是附加语. beantworten 和 schreiben 的区别正在于此: 二者都带宾语, 但 schreiben 的宾语可以省.

必有、可选和自由的句子成分
Obligatorische, fakultative und optionale Satzglieder

Folie 30
  • Obligatorisches Satzglied = Komplement (valenzgefordert):
    *Er beantwortet einen Brief
  • Fakultatives Satzglied = Komplement, aber kontextabhängig eliminierbar:
    Er schreibt einen Brief
    → Ellipse eines an sich obligatorischen Satzglieds
    → oder Annahme von zwei Valenzrahmen
  • Optionales Satzglied = Adjunkt (immer eliminierbar):

Er schreibt den ganzen Tag

  • Differenzierung fakultativer von optionalen Satzgliedern:
    beide: eliminierbar → Differenzierung über geschehens-Test:

*Er schreibt, und es geschieht einen Brief (fakultatives Komplement)
Er schreibt, und es geschieht den ganzen Tag (Adjunkt, optionales Satzglied)

  • obligatorisch 必有的句子成分 = 补足语 (配价要求的): *Er beantwortet (缺宾语).
  • fakultativ 可选的句子成分 = 补足语, 但在一定语境下可以省略: Er schreibt (他在写东西) → 可以看作本来必有的成分被省略了 (Ellipse 省略), 或者认为 schreiben 有两个配价框架 (及物的「写某物」和不及物的「写作」).
  • optional 自由的句子成分 = 附加语 (总能省略): Er schreibt den ganzen Tag (他整天写).
  • 区分可选成分和自由成分: 两者都能删, 要靠 geschehen 测试区分: 「*他写, 这件事发生了一封信」不合语法 (可选补足语); 「他写, 这件事持续了一整天」合语法 (附加语, 自由成分).
能删吗geschehen 测试类型
obligatorisch (einen Brief bei beantworten)不能失败补足语
fakultativ (einen Brief bei schreiben)能失败补足语
optional (den ganzen Tag)能成功附加语

单看一个测试都会出错, 组合起来才可靠. 记这张表: 删除测试分出「必有」和「其余」, geschehen 测试再把「其余」分成可选补足语和附加语. 「den ganzen Tag」是四格 (宾格) 却不是宾语, 而是时间状语: 不能看格判断功能.

术语三分法里「fakultativ」和「optional」在日常德语里都是「可选」, 这门课把它们区分开: fakultativ 专指可以省略的补足语, optional 专指附加语. 写作业和考试时要用对词.
